피그마 `Web/Bar Chart/Ranked Bar`를 옮긴 순위 막대 차트입니다. 항목을 값이 큰 순서로 늘어놓고, 1위부터 3위까지 진한 청록에서 옅은 청록으로 칠하며, 4위부터는 같은 색으로 둡니다. 막대 위에는 숫자와 단위를, 막대 안이나 위에는 이름을 적습니다. "지부별 지원 현황"처럼 대상끼리 순위를 견줄 때 씁니다.

```tsx
import { RankedBarChart } from "@umc-product/react"

<RankedBarChart
  aria-label="지부별 지원 현황"
  unit="명"
  items={[
    { key: "neon", label: "Neon", value: 100 },
    { key: "chromium", label: "Chromium", value: 89 },
    { key: "platinum", label: "Platinum", value: 71 },
  ]}
/>
```

<RankedBarChartDefault client:visible />

## 순위

넘긴 순서와 상관없이 값이 큰 순서로 늘어놓습니다. 값이 같으면 같은 순위이고, 다음 순위는 같은 순위인 항목 수만큼 건너뜁니다(예: 1, 2, 2, 4위). 같은 값끼리는 넘긴 순서를 지킵니다. 값이 0이면 순위 없이 맨 뒤에 둡니다.

## 막대 높이

기본(`heightBy="value"`)은 가장 큰 값의 막대가 200px이고 나머지는 값에 비례합니다. 배경 기준선은 높이의 20%마다 하나씩 그립니다. 정원처럼 고정된 기준이 있으면 `max`로 넘깁니다.

- 막대가 28px 이상이면 이름을 막대 안에 적습니다. 막대 높이에 들어가는 줄만큼(최대 여섯 줄) 보여 주고, 더 길면 마지막 줄을 말줄임으로 끝냅니다.
- 그보다 낮으면 이름을 막대 위에 한 줄로 적고, 넘치면 말줄임으로 자릅니다.
- 0보다 큰 값은 2px보다 낮아지지 않고, 0은 1px 막대로 그립니다.

## 비교값

항목에 `reference`를 넘기면 그 값만큼의 회색 막대를 뒤에 겹쳐 그립니다. 평가를 마친 사람 수를 지원자 수와 견줄 때 씁니다. 비교값도 막대 높이의 기준에 들어가고, 비교 막대는 32px보다 낮아지지 않습니다.

<RankedBarChartReference client:visible />

## 순위 고정 높이

`heightBy="rank"`이면 값과 상관없이 순위마다 정해진 높이로 그립니다. 1위부터 5위까지를 보여 주는 자리에 씁니다. 5위부터는 막대 위에 이름을 적는 낮은 막대이고, 값이 0이면 숫자와 이름 없이 회색 막대만 남습니다. 이 모드에서는 비교 막대와 배경 기준선을 그리지 않습니다.

## 툴팁

막대에 마우스를 올리거나 키보드로 가거나 누르면 [ChartTooltip](../chart-tooltip/) 모양의 요약이 뜹니다. 따로 넘기지 않으면 제목은 이름, 합계는 값(비교값이 있으면 "값 / 비교값")입니다. 파트별 내역처럼 다른 내용을 보여 주려면 항목의 `tooltip`을 넘깁니다.

## 접근성

- 막대마다 버튼이고, 버튼 이름은 항목 이름입니다. 순위와 값(비교값이 있으면 "값 / 비교값")은 늘 버튼 설명으로 읽히고, `tooltip`을 넘기면 그 내용이 뒤에 이어집니다. 같은 순위는 "공동 4위"처럼 읽습니다.
- 막대 위 숫자와 툴팁은 버튼 설명과 내용이 같아 화면 낭독기에서 숨깁니다.
- Tab은 차트에서 한 번만 멈추고, 막대 사이는 화살표 키, Home, End로 옮깁니다.
- 무엇을 나타내는 차트인지 `aria-label`로 알립니다.

## 모든 변형

피그마 `Web/Bar Chart/Ranked Bar` 변형 25개와 `Web/Bar Chart/Fixed Ranked Bar` 변형 6개를 그렸습니다. 순위 색은 앞 순위 막대가 있어야 정해지므로, 칸마다 앞 순위 막대를 함께 넣고 마지막 막대만 보여 줍니다.

## props

네이티브 `ul` 속성을 받습니다.

| prop          | 타입                            | 기본값                    | 설명                                          |
| ------------- | ------------------------------- | ------------------------- | --------------------------------------------- |
| `items`       | `readonly RankedBarChartItem[]` | -                         | 항목 목록(필수). 값이 큰 순서로 다시 늘어놓음 |
| `unit`        | `ReactNode`                     | -                         | 숫자 뒤에 붙일 단위(예: `"명"`)               |
| `heightBy`    | `"value" \| "rank"`             | `"value"`                 | 막대 높이를 값과 순위 중 무엇으로 정할지      |
| `max`         | `number`                        | 값과 비교값 중 가장 큰 값 | `heightBy="value"`에서 200px이 되는 값        |
| `formatValue` | `(value: number) => ReactNode`  | 천 단위 쉼표를 넣은 숫자  | 숫자의 형식                                   |
| `aria-label`  | `string`                        | -                         | 차트가 나타내는 것                            |
| `className`   | `string`                        | -                         | 목록에 더할 CSS 클래스                        |

`RankedBarChartItem`은 항목 하나의 정보입니다.

| 필드        | 타입                  | 설명                                            |
| ----------- | --------------------- | ----------------------------------------------- |
| `key`       | `string`              | 항목을 가리키는 고유한 이름(필수)               |
| `label`     | `ReactNode`           | 막대 안이나 위에 적을 이름(필수)                |
| `value`     | `number`              | 값(필수). 0보다 작거나 숫자가 아니면 0          |
| `reference` | `number`              | 비교값. `heightBy="value"`에서 회색 막대로 그림 |
| `tooltip`   | `ChartTooltipContent` | 툴팁의 합계, 비교 합계, 항목, 보조 설명         |

## 알아 둘 점

- 막대 하나의 폭은 82px(순위 고정 높이는 72px)이고 막대 사이는 10px입니다. 10개를 넣으면 약 930px이 되어, 좁은 화면에서는 가로로 스크롤합니다.
- 항목은 10개까지 넣는 것을 전제로 한 모양입니다. 더 넣어도 자르지 않습니다.
