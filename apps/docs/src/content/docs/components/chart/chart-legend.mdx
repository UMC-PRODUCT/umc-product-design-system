피그마 `Chart/Legend Item`을 옮긴 범례입니다. 계열 목록(`series`)을 받아 색 점과 이름을 한 줄로 늘어놓습니다. 차트 카드 제목의 오른쪽에 두고, 차트에 넘기는 계열 목록을 범례에도 그대로 넘기면 범례와 막대의 색이 어긋나지 않습니다.

```tsx
import { ChartLegend, type ChartSeries } from "@umc-product/react"

const parts: ChartSeries[] = [
  { key: "pm", label: "PM", color: "pm" },
  { key: "design", label: "Design", color: "design" },
  { key: "web-pe", label: "Web PE", color: "web-pe" },
  { key: "mobile-pe", label: "Mobile PE", color: "mobile-pe" },
]

<ChartLegend series={parts} aria-label="파트" />
```

## 색

`color`는 쓰임에 따라 고르는 이름 9개 중 하나입니다.

| `color`                                        | 쓰는 곳                                                 |
| ---------------------------------------------- | ------------------------------------------------------- |
| `pm`, `design`, `web-pe`, `mobile-pe`          | 파트끼리 나눠 볼 때. 파트 태그와 같은 색 계열입니다     |
| `teal-500`, `teal-400`, `teal-300`, `teal-200` | 1차, 2차 지원처럼 이어지는 계열. 앞 단계일수록 진합니다 |
| `reference`                                    | 지원자 수처럼 다른 값과 견주는 기준 값                  |

<ChartLegendWrap />

## 접근성

- 목록(`ul`)으로 그리고, 색 점은 화면 낭독기에서 숨깁니다. 계열은 이름 글자로 구분합니다.
- 범례가 무엇을 나누는지 알려야 하면 `aria-label`을 넘깁니다(예: "파트").
- 강제 색 모드에서도 색 점의 색을 그대로 두고 테두리를 더해, 차트 막대와 짝을 맞출 수 있게 합니다.

## props

네이티브 `ul` 속성을 받습니다.

| prop         | 타입                     | 기본값 | 설명                   |
| ------------ | ------------------------ | ------ | ---------------------- |
| `series`     | `readonly ChartSeries[]` | -      | 계열 목록(필수)        |
| `aria-label` | `string`                 | -      | 범례가 나누는 기준     |
| `className`  | `string`                 | -      | 목록에 더할 CSS 클래스 |

`ChartSeries`는 계열 하나의 정보입니다.

| 필드    | 타입         | 설명                              |
| ------- | ------------ | --------------------------------- |
| `key`   | `string`     | 계열을 가리키는 고유한 이름(필수) |
| `label` | `ReactNode`  | 범례와 툴팁에 보이는 이름(필수)   |
| `color` | `ChartColor` | 위 색 표의 이름 중 하나(필수)     |

## 알아 둘 점

- 범례는 색만 정합니다. 어떤 계열을 어떤 순서로 보여 줄지는 넘긴 목록의 순서를 따릅니다.
