피그마 `Date Navigator`를 옮긴 컴포넌트입니다. 가운데에 지금 보고 있는 날짜를, 양옆에 이전과 다음으로 옮기는 화살표를 둡니다. [ColumnChart](../column-chart/) 위에서 차트가 보여 줄 날짜를 고를 때 씁니다.

```tsx
import { DateNavigator } from "@umc-product/react"

<DateNavigator
  aria-label="날짜"
  onPrevious={showPreviousDay}
  onNext={isToday ? undefined : showNextDay}
>
  2026년 10월 20일
</DateNavigator>
```

<DateNavigatorDefault client:visible />

## 끝에 닿았을 때

더 옮길 수 없는 쪽은 콜백을 넘기지 않습니다. 그쪽 화살표는 비활성이 되어 흐리게 보이고, 눌러도 아무 일이 없습니다. 위 예시는 오늘에서 다음 화살표가 비활성입니다. 키보드로 눌러 끝에 닿아도 초점은 그 화살표에 남습니다.

## 날짜가 아닌 기간

가운데 글자는 앱이 정해 `children`으로 넘기므로 주나 달도 그대로 쓸 수 있습니다. 화살표 이름은 `previousLabel`, `nextLabel`로 바꿉니다.

<DateNavigatorWeek client:visible />

## 접근성

- 화살표는 버튼이고 기본 이름은 "이전", "다음"입니다. 비활성은 `aria-disabled`로 알려서 초점을 잃지 않습니다. 주를 옮기면 "이전 주"처럼 무엇을 옮기는지 이름에 넣습니다.
- 가운데 글자는 알림 영역이라 화살표를 누른 뒤 바뀐 날짜를 화면 낭독기가 읽습니다.
- 그룹 이름은 `aria-label`로 넘깁니다.
- 화살표 그림은 작지만 누르는 영역은 위아래 5px, 양옆 8px 넓습니다.

## props

네이티브 `div` 속성을 받습니다.

| prop            | 타입         | 기본값   | 설명                                        |
| --------------- | ------------ | -------- | ------------------------------------------- |
| `children`      | `ReactNode`  | -        | 지금 날짜나 기간(필수)                      |
| `onPrevious`    | `() => void` | -        | 이전으로 옮길 때. 없으면 이전 화살표 비활성 |
| `onNext`        | `() => void` | -        | 다음으로 옮길 때. 없으면 다음 화살표 비활성 |
| `previousLabel` | `string`     | `"이전"` | 이전 화살표의 접근 가능한 이름              |
| `nextLabel`     | `string`     | `"다음"` | 다음 화살표의 접근 가능한 이름              |
| `aria-label`    | `string`     | -        | 그룹 이름                                   |
| `className`     | `string`     | -        | 루트에 더할 CSS 클래스                      |

## 알아 둘 점

- 날짜 형식과 이동 단위(하루, 한 주)는 앱이 정합니다. 컴포넌트는 날짜를 계산하지 않습니다.
