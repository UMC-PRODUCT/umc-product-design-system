피그마 `Chart/Tooltip`을 옮긴 요약 상자입니다. 학교나 지부처럼 차트의 한 묶음에 담긴 값을 제목, 합계, 항목 순서로 보여 줍니다. [CategoryGroupChart](../category-group-chart/)는 묶음에 마우스를 올리거나 누를 때 이 상자를 띄웁니다. 같은 모양의 요약이 필요한 다른 화면에서는 이 컴포넌트를 바로 씁니다.

```tsx
import { ChartTooltip } from "@umc-product/react"

<ChartTooltip
  title="한국대 ERICA"
  summary="120명 지원"
  items={[
    { key: "pm", label: "PM", color: "pm", value: "16명" },
    { key: "design", label: "Design", color: "design", value: "34명" },
  ]}
/>
```

<ChartTooltipDefault />

## 비교값

항목에 `reference`를 넘기면 값 옆에 비교값을 "10명 / 16명"처럼 붙이고, 이름과 값을 양 끝으로 벌립니다. 합계의 비교값은 `referenceSummary`로 넘기면 합계 뒤에 "/ 120명 지원"처럼 이어 붙입니다. 평가를 마친 사람 수를 지원자 수와 견줄 때 씁니다.

## 보조 설명

`caption`을 넘기면 맨 아래에 회색 글자로 덧붙입니다. 집계 시각처럼 값을 읽는 데 필요한 조건을 적습니다.

<ChartTooltipCaption />

## 접근성

- 항목은 목록(`ul`)으로 그리고, 색 점과 화살표는 화면 낭독기에서 숨깁니다.
- 글자는 줄을 바꾸지 않습니다. 이름이 길면 상자가 넓어집니다.

## props

네이티브 `div` 속성을 받습니다. 네이티브 `title` 속성 대신 상자의 제목을 받습니다.

| prop               | 타입                          | 기본값 | 설명                                     |
| ------------------ | ----------------------------- | ------ | ---------------------------------------- |
| `title`            | `ReactNode`                   | -      | 묶음 이름(필수). 학교명, 지부명 등       |
| `summary`          | `ReactNode`                   | -      | 합계 줄. 청록 굵은 글자                  |
| `referenceSummary` | `ReactNode`                   | -      | 합계의 비교값. 합계 뒤에 `/`로 이어 붙임 |
| `items`            | `readonly ChartTooltipItem[]` | -      | 항목 목록                                |
| `caption`          | `ReactNode`                   | -      | 맨 아래 보조 설명                        |
| `className`        | `string`                      | -      | 루트에 더할 CSS 클래스                   |

`ChartTooltipItem`은 항목 하나의 정보입니다.

| 필드        | 타입         | 설명                               |
| ----------- | ------------ | ---------------------------------- |
| `key`       | `string`     | 항목을 가리키는 고유한 이름(필수)  |
| `label`     | `ReactNode`  | 항목 이름(필수)                    |
| `color`     | `ChartColor` | 색 점의 색(필수). 범례와 같은 이름 |
| `value`     | `ReactNode`  | 값(필수). 단위까지 붙여 넘김       |
| `reference` | `ReactNode`  | 비교값. 넘기면 비교 모양으로 그림  |

## 알아 둘 점

- 값의 단위와 숫자 형식은 앱이 정해 글자로 넘깁니다(예: `"10명"`).
- 위쪽 화살표는 상자 위에 있는 막대를 가리킵니다. 차트 안에서는 아래쪽에 자리가 없으면 상자가 위로 뒤집히고 화살표도 아래를 가리킵니다.
