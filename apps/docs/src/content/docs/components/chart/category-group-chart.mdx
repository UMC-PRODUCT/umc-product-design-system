피그마 `Bar Chart/Category Group`을 옮긴 막대 차트입니다. 학교나 프로젝트 같은 묶음마다 파트나 차수 같은 계열의 값을 가는 막대로 나란히 세웁니다. 묶음에 마우스를 올리거나 키보드로 가거나 누르면 [ChartTooltip](../chart-tooltip/) 모양의 요약이 뜹니다.

```tsx
import { CategoryGroupChart, ChartLegend } from "@umc-product/react"

const parts = [
  { key: "pm", label: "PM", color: "pm" },
  { key: "design", label: "Design", color: "design" },
] as const

<ChartLegend series={parts} aria-label="파트" />
<CategoryGroupChart
  aria-label="학교별 지원 현황"
  series={parts}
  groups={[
    {
      key: "erica",
      label: "한국대 ERICA",
      values: { pm: 16, design: 34 },
      tooltip: { summary: "50명 지원" },
    },
  ]}
  formatValue={(value) => `${value}명`}
/>
```

<CategoryGroupChartDefault client:visible />

## 막대 높이

막대 높이는 값을 차트 전체에서 가장 큰 값으로 나눈 비율입니다. 가장 많이 지원한 학교의 가장 많은 파트가 막대 칸(100px)을 가득 채웁니다. 값이 0이면 높이 2px의 막대만 남겨 "값 없음"을 보여 줍니다. 정원처럼 고정된 기준이 있으면 `max`로 넘깁니다.

## 비교값

묶음에 `references`를 넘기면 계열마다 회색 비교 막대를 값 막대 뒤에 겹쳐 그립니다. 평가를 마친 사람 수를 지원자 수와 견줄 때 씁니다. 비교값도 막대 높이의 기준(가장 큰 값)에 들어갑니다. 툴팁 항목은 "10명 / 16명"처럼 값과 비교값을 함께 보여 주고, 합계는 `tooltip`의 `summary`와 `referenceSummary`로 넘깁니다.

<CategoryGroupChartReference client:visible />

## 이어지는 계열

1차, 2차, 3차 지원처럼 순서가 있는 계열은 청록 단계(`teal-500`, `teal-400`, `teal-300`)로 칠합니다. 앞 단계일수록 진합니다.

## 툴팁

- 마우스를 올리면 바로 뜨고 묶음과 툴팁에서 모두 벗어나면 닫힙니다. 화면을 확대한 사용자가 툴팁 위로 마우스를 옮겨 읽을 수 있습니다.
- 키보드로 묶음에 가면 뜨고 Esc로 닫습니다.
- 터치 화면에서는 묶음을 누르면 뜨고 다시 누르거나 바깥을 누르면 닫힙니다.
- 아래쪽에 자리가 없으면 묶음 위로 뒤집혀 뜹니다.
- 제목은 묶음 이름입니다. 항목은 따로 넘기지 않으면 계열마다 `formatValue`로 쓴 값을 채웁니다. 내용을 통째로 바꾸려면 묶음의 `tooltip.items`를 넘깁니다.

## 접근성

- 묶음마다 버튼이고, 버튼 이름은 묶음 이름입니다. 합계와 계열 값은 버튼 설명으로 함께 읽힙니다.
- 툴팁은 버튼 설명과 내용이 같아 화면 낭독기에서 숨깁니다.
- Tab은 차트에서 한 번만 멈추고, 묶음 사이는 화살표 키로 옮깁니다. Home과 End는 처음과 끝 묶음으로 갑니다.
- 무엇을 나타내는 차트인지 `aria-label`로 알립니다.
- 강제 색 모드에서도 막대 색을 그대로 두고 테두리를 더합니다. 배경 기준선은 그리지 않습니다.

## props

네이티브 `ul` 속성을 받습니다.

| prop          | 타입                                  | 기본값                    | 설명                                        |
| ------------- | ------------------------------------- | ------------------------- | ------------------------------------------- |
| `series`      | `readonly CategoryGroupChartSeries[]` | -                         | 계열 목록(필수). 범례에 그대로 넘길 수 있음 |
| `groups`      | `readonly CategoryGroupChartGroup[]`  | -                         | 묶음 목록(필수). 넘긴 순서대로 그림         |
| `max`         | `number`                              | 값과 비교값 중 가장 큰 값 | 막대가 가득 차는 값                         |
| `formatValue` | `(value: number) => ReactNode`        | 천 단위 쉼표를 넣은 숫자  | 툴팁과 설명에 쓸 값의 형식                  |
| `aria-label`  | `string`                              | -                         | 차트가 나타내는 것                          |
| `className`   | `string`                              | -                         | 목록에 더할 CSS 클래스                      |

`CategoryGroupChartSeries`는 `ChartSeries`와 같고, `color`는 파트 4종(`pm`, `design`, `web-pe`, `mobile-pe`)과 청록 3단계(`teal-500`, `teal-400`, `teal-300`) 중에서 고릅니다.

`CategoryGroupChartGroup`은 묶음 하나의 정보입니다.

| 필드         | 타입                     | 설명                                         |
| ------------ | ------------------------ | -------------------------------------------- |
| `key`        | `string`                 | 묶음을 가리키는 고유한 이름(필수)            |
| `label`      | `ReactNode`              | 막대 아래 이름(필수)                         |
| `values`     | `Record<string, number>` | 계열 `key`별 값(필수). 빠진 계열은 0         |
| `references` | `Record<string, number>` | 계열 `key`별 비교값. 넘기면 비교 막대를 그림 |
| `tooltip`    | `ChartTooltipContent`    | 툴팁의 합계, 비교 합계, 항목, 보조 설명      |

## 알아 둘 점

- 묶음 하나는 폭 60px, 높이 147px입니다. 계열이 5개를 넘으면 막대가 묶음 폭을 넘어 묶음이 넓어집니다.
- 묶음 이름은 띄어쓰기에서 줄을 바꾸고 두 줄까지 보여 줍니다. 띄어쓰기 없이 긴 이름은 글자 단위로 넘기고, 세 줄부터는 말줄임으로 자릅니다. 툴팁 제목에는 전체 이름이 나옵니다.
- 묶음 순서(예: 지부 가나다 순, 지부 안 학교 가나다 순)는 앱이 정해 넘깁니다.
