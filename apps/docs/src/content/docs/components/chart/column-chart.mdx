피그마 `Bar Chart/Column`을 옮긴 막대 차트입니다. 항목마다 막대 위에 값을, 아래에 이름을 적습니다. "최근 8일 지원자 수"처럼 순서가 있는 값을 웹과 앱에서 한눈에 견줄 때 씁니다.

```tsx
import { ColumnChart } from "@umc-product/react"

<ColumnChart
  aria-label="최근 8일 지원자 수"
  items={[
    { key: "10-19", label: "19(월)", value: 11 },
    { key: "10-20", label: "20(화)", value: 4, mode: "primary-strong" },
  ]}
  formatValue={(value) => `${value}명`}
/>
```

<ColumnChartDefault />

## 막대 모양

`mode`로 막대마다 모양을 고릅니다. 기본은 회색 `neutral`이고, 오늘이나 고른 날처럼 눈에 띄어야 하는 막대에 청록 `primary-strong`을 씁니다. 옅은 청록 `primary-weak`은 강조 막대와 구분할 다른 값에 씁니다.

<ColumnChartModes />

## 막대 높이

막대 높이는 값을 가장 큰 값으로 나눈 비율입니다. 가장 큰 값의 막대가 칸을 가득 채우고, 값이 0이면 막대 없이 값만 남습니다. 정원처럼 고정된 기준이 있으면 `max`로 넘깁니다. `max`를 넘는 값은 가득 찬 막대로 그립니다.

## 접근성

- 목록(`ul`)으로 그리고 항목마다 이름을 먼저, 값을 다음에 읽습니다. 화면에는 값이 위에 있지만 "20(화), 4명" 순서로 읽힙니다.
- 무엇을 나타내는 차트인지 `aria-label`로 알립니다.
- 막대는 화면 낭독기에서 숨깁니다. 값은 글자로 함께 적혀 있습니다.
- 강제 색 모드에서도 막대 색을 그대로 두고 테두리를 더합니다.

## props

네이티브 `ul` 속성을 받습니다.

| prop          | 타입                           | 기본값                   | 설명                                |
| ------------- | ------------------------------ | ------------------------ | ----------------------------------- |
| `items`       | `readonly ColumnChartItem[]`   | -                        | 항목 목록(필수). 넘긴 순서대로 그림 |
| `max`         | `number`                       | 가장 큰 값               | 막대가 가득 차는 값                 |
| `formatValue` | `(value: number) => ReactNode` | 천 단위 쉼표를 넣은 숫자 | 막대 위에 적을 값의 형식            |
| `aria-label`  | `string`                       | -                        | 차트가 나타내는 것                  |
| `className`   | `string`                       | -                        | 목록에 더할 CSS 클래스              |

`ColumnChartItem`은 항목 하나의 정보입니다.

| 필드    | 타입              | 설명                                                    |
| ------- | ----------------- | ------------------------------------------------------- |
| `key`   | `string`          | 항목을 가리키는 고유한 이름(필수)                       |
| `label` | `ReactNode`       | 막대 아래 이름(필수)                                    |
| `value` | `number`          | 값(필수). 0보다 작거나 숫자가 아니면 0으로 그림         |
| `mode`  | `ColumnChartMode` | `"neutral"`(기본), `"primary-weak"`, `"primary-strong"` |

## 알아 둘 점

- 칸 하나는 폭 40px, 높이 164px로 고정이고, 칸 사이는 남는 폭을 고르게 나눕니다. 360px 폭에는 8칸이 알맞고, 부모 폭보다 칸이 많으면 가로로 스크롤합니다.
- 이름과 값은 줄을 바꾸지 않습니다. 이름은 "20(화)"처럼 짧게 줄여 넘깁니다.
