`direction`으로 말풍선 방향을 지정합니다. 꼬리는 `fill="currentColor"` 인라인 SVG로 배경색을 그대로 따릅니다.

```tsx
import { Bubble } from "@umc-product/react"

<Bubble direction="incoming">UMC PRODUCT 모여라</Bubble>
<Bubble direction="outgoing">함께 성장합시다</Bubble>
```

## props

| prop        | 타입                       | 기본값       | 설명                     |
| ----------- | -------------------------- | ------------ | ------------------------ |
| `direction` | `"incoming" \| "outgoing"` | `"incoming"` | 말풍선 방향              |
| `children`  | `ReactNode`                | 필수         | 말풍선 내용              |
| `className` | `string`                   | 없음         | 루트 `div`에 붙일 클래스 |
| `ref`       | `Ref<HTMLDivElement>`      | 없음         | 루트 `div` 참조          |

그 밖에 `div` 속성을 그대로 넘깁니다.

## 알아 둘 점

- 수신 말풍선은 배경이 흰색이라 흰 화면에서는 경계가 보이지 않습니다. 회색 배경 위에 놓습니다.
- `forced-colors` 모드에서는 꼬리를 숨기고 버블 body에 `inset 0 0 0 1px CanvasText` 테두리를 추가합니다.
