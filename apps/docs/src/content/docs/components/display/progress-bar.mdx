`value`로 완료 비율을 지정합니다. Base UI Progress 위에 구현해 스크린 리더가 `role="progressbar"`, `aria-valuenow`, `aria-valuemax`를 자동으로 읽습니다. 너비는 컨테이너를 채우며, `size`로 굵기를 선택합니다.

```tsx
import { ProgressBar } from "@umc-product/react"

function Example() {
  return (
    <ProgressBar
      value={60}
      size="md"
      color="brand"
      aria-label="파일 업로드 진행률"
    />
  )
}
```

## props

| prop         | 타입                                           | 기본값    | 설명                         |
| ------------ | ---------------------------------------------- | --------- | ---------------------------- |
| `value`      | `number`                                       | 필수      | 현재 진행 값 (0–100)         |
| `max`        | `number`                                       | `100`     | 최댓값                       |
| `size`       | `"md" \| "lg"`                                 | `"md"`    | 바 굵기 (5px, 8px)           |
| `color`      | `"brand" \| "neutral" \| "success" \| "error"` | `"brand"` | 인디케이터 색상 의미         |
| `aria-label` | `string`                                       |           | 접근 가능한 이름 (필수 권장) |
| `ref`        | `Ref<HTMLDivElement>`                          |           | 루트 요소 ref                |
| `className`  | `string`                                       |           | 추가 클래스                  |

나머지 `div` 속성은 루트 요소에 전달됩니다. 네이티브 `color` 속성은 제외됩니다.

## 알아 둘 점

- `aria-label`이 없으면 스크린 리더가 바를 식별하지 못합니다. 항상 의미 있는 레이블을 제공합니다.
- `prefers-reduced-motion: no-preference` 환경에서 인디케이터 너비가 전환 애니메이션으로 변합니다.
- `forced-colors` 모드에서는 트랙이 `ButtonFace`, 인디케이터가 `Highlight`로 그려집니다.
