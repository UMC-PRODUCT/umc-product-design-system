피그마 `Progress Summary`를 옮긴 컴포넌트입니다. 라벨 옆에 개수(마친 수/전체 수)를, 오른쪽에 퍼센트를 두고 아래에 진행 막대를 그립니다. "서류 합격자 42명 중 21명의 면접 배정을 마쳤다"처럼 대시보드에서 한 단계의 진행을 요약할 때 씁니다. 막대만 필요한 자리에는 [ProgressBar](../progress-bar/)가 맞습니다.

```tsx
import { ProgressSummary } from "@umc-product/react"

<ProgressSummary label="면접 배정률" value={assignedCount} max={passedCount} />
```

## 퍼센트

퍼센트는 `value / max`를 반올림한 정수입니다. 다만 아래 두 경우는 반올림 결과를 그대로 쓰지 않습니다.

- 아직 끝나지 않았으면 99%에서 멈춥니다. 200명 중 199명은 99.5%라 반올림하면 100%가 되지만 99%로 보여 줍니다.
- 하나라도 마쳤으면 1%부터 보여 줍니다. 1,000명 중 1명은 0.1%지만 0%가 아니라 1%입니다.

`max`가 0이면 대상이 아직 없다는 뜻이라 0%입니다. `value`가 `max`보다 크면 100%로 보여 주고, 개수는 넘긴 값을 그대로 적습니다. 막대 길이도 화면에 적힌 퍼센트를 따릅니다.

## 폭

부모 폭을 채우므로 카드나 그리드 칸에 넣고 폭은 바깥에서 정합니다. 라벨이 길어 한 줄에 들어가지 않으면 라벨 끝을 말줄임표로 자릅니다. 개수와 퍼센트는 줄이지 않습니다.

<ProgressSummaryWidths />

## 접근성

- 루트가 `progressbar`이고 `label`이 이름입니다. 화면 낭독기는 "면접 배정률, 50%"처럼 이름과 퍼센트를 읽고, 개수 "(21/42)"는 설명으로 읽습니다.
- 화면의 퍼센트 글자는 값과 내용이 같아 화면 낭독기에서 숨깁니다.
- 분모와 분자가 무엇인지 알려야 하면 그 문장의 id를 `aria-describedby`로 넘깁니다. 개수 다음에 이어서 읽힙니다.

## props

네이티브 `div` 속성을 받습니다.

| prop               | 타입        | 기본값 | 설명                                  |
| ------------------ | ----------- | ------ | ------------------------------------- |
| `label`            | `ReactNode` | -      | 라벨(필수). `progressbar`의 이름이 됨 |
| `value`            | `number`    | -      | 마친 수(필수)                         |
| `max`              | `number`    | -      | 전체 수(필수). 0이면 퍼센트가 0%      |
| `aria-describedby` | `string`    | -      | 개수 다음에 이어 읽을 설명 요소의 id  |
| `className`        | `string`    | -      | 루트에 더할 CSS 클래스                |

## 알아 둘 점

- 채움 막대는 왼쪽에서 오른쪽으로 갈수록 옅어지는 청록 그라데이션입니다. 강제 색 모드에서는 시스템 강조색(`Highlight`) 단색으로 그립니다.
- `value`가 바뀌면 막대가 늘어나거나 줄어드는 움직임이 있습니다. 움직임 줄이기 설정을 켠 사용자에게는 움직임 없이 바뀝니다.
