피그마 `Text Field/ Input Box`(node 2621:33115)의 상자입니다. `TextField`, `TextArea`, `VerificationCodeField`가 이 상자를 씁니다. 직접 쓰는 경우는 피그마 `Type=Custom`처럼 안쪽을 자유롭게 채울 때입니다.

```tsx
import { InputBox } from "@umc-product/react"

<InputBox size="md">
  <input className="umc-input-box__input" aria-label="앞자리" />
  <span aria-hidden="true">-</span>
  <input className="umc-input-box__input" aria-label="뒷자리" />
</InputBox>
```

## 상태

상태는 상자 하나가 CSS로 정합니다. 마우스를 올리거나 포커스하면 테두리가 `--umc-color-border-primary-strong-500`으로 바뀌고, 값이 있는 채로 포커스하면(피그마 Typing) 배경이 옅은 청록으로 바뀝니다.

| 상태          | 테두리                                                 | 배경                                 |
| ------------- | ------------------------------------------------------ | ------------------------------------ |
| 기본          | `--umc-color-border-neutral-medium-300`                | `--umc-color-fill-neutral-default`   |
| hover, 포커스 | `--umc-color-border-primary-strong-500`                | 기본과 같음                          |
| 입력 중       | `--umc-color-border-primary-strong-500`                | `#f4fbfa99`(피그마 값)               |
| 오류          | 빈 값 red-300, hover와 포커스 red-400, 채운 값 red-500 | `--umc-color-fill-error-weak-50`     |
| 비활성        | `--umc-color-border-neutral-weaker-100`                | `--umc-color-fill-neutral-weaker-50` |

`invalid`가 켜지는 순간 상자가 좌우로 흔들립니다(피그마 주석 "에러 시 양쪽 도리도리 흔들리는 인터렉션"). 동작 줄이기 설정에서는 흔들지 않습니다.

## 모든 변형

피그마 `Text Field/ Input Box`의 Custom 변형 10개와 `.primitive/ Text Field/ Accessory` 6개를 그렸습니다. 부속 요소는 그 요소가 나타나는 필드 안에 그렸습니다. 칸에 마우스를 올리면 피그마 변형 이름이 보입니다. Hover, Focus, Typing처럼 마우스나 키보드가 있어야 보이는 상태는 문서에서 켜 둔 모습입니다.

## props

| prop       | 타입           | 기본값 | 설명                |
| ---------- | -------------- | ------ | ------------------- |
| `size`     | `"lg" \| "md"` | `"lg"` | 높이 48px 또는 44px |
| `invalid`  | `boolean`      | 없음   | 오류 상태           |
| `disabled` | `boolean`      | 없음   | 비활성 상태         |

나머지 `div` 속성은 그대로 전달합니다. 값이 있는지는 안쪽 컨트롤의 `data-filled`로 판단하므로 `FieldControl`을 쓰면 입력 중 배경이 자동으로 적용됩니다.

## 피그마와 다른 점

- 비활성 테두리: `Input Box`는 2기 변수 `warmgray-150`(#efedeb), `Text Field/ Box`는 `TealGrey-100`(#eff0f0)을 씁니다. 3기 토큰 `--umc-color-border-neutral-weaker-100`로 통일했습니다.
- Lg 기본 상태의 placeholder만 16px이고 나머지 상태는 18px입니다. 상태가 바뀔 때 글자 크기가 튀지 않도록 Lg는 모두 18px(`Label/1-Medium`)로 맞췄습니다.
