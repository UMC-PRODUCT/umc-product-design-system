피그마 `Code Field`(노드 2621:33470)를 구현합니다. Base UI `OTPField`를 사용하며 붙여넣기, 자동완성, 포커스 이동을 지원합니다.

```tsx
import { CodeField } from "@umc-product/react"

;<CodeField
  label="인증코드"
  length={6}
  onValueComplete={(code) => verifyCode(code)}
  invalid={isInvalid}
  errorMessage="올바르지 않은 코드입니다"
/>
```

## props

| prop              | 타입                  | 기본값  | 설명                         |
| ----------------- | --------------------- | ------- | ---------------------------- |
| `length`          | `number`              | `6`     | 슬롯(입력 칸) 수             |
| `value`           | `string`              | 없음    | 제어 컴포넌트 값             |
| `defaultValue`    | `string`              | 없음    | 비제어 초기값                |
| `onValueChange`   | `(v: string) => void` | 없음    | 값 변경 콜백                 |
| `onValueComplete` | `(v: string) => void` | 없음    | 모든 슬롯이 채워졌을 때 호출 |
| `mask`            | `boolean`             | `false` | 입력 값 마스킹               |
| `name`            | `string`              | 없음    | form 제출 시 필드 이름       |
| `invalid`         | `boolean`             | `false` | 모든 슬롯에 오류 스타일 적용 |
| `errorMessage`    | `ReactNode`           | 없음    | `invalid`일 때 표시          |
