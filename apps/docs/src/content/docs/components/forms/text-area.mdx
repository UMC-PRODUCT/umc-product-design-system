피그마 `Text Field/ Input Box`의 `Type=Text Area`를 구현했습니다. 상자는 `InputBox`와 같고 안쪽 여백만 위아래 12px, 좌우 16px입니다. 네이티브 `textarea` 속성과 `ref`를 그대로 받습니다.

```tsx
import { TextArea } from "@umc-product/react"

<TextArea label="지원 동기" rows={4} {...register("motivation")} />
```

## props

`Field`의 props와 네이티브 `textarea` 속성을 받습니다.

| prop   | 타입           | 기본값 | 설명                     |
| ------ | -------------- | ------ | ------------------------ |
| `size` | `"lg" \| "md"` | `"lg"` | 글자 크기 18px 또는 16px |
| `rows` | `number`       | `2`    | 처음 높이(줄 수)         |

높이는 사용자가 세로로만 늘릴 수 있습니다.
