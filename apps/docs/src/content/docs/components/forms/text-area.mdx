피그마 `TextArea`(노드 2621:33262)를 구현합니다. `InputBox`를 기반으로 하며, `rows`, `maxLength`, `placeholder` 등 네이티브 `textarea` 속성을 모두 받습니다.

```tsx
import { TextArea } from "@umc-product/react"

;<TextArea
  label="자기소개"
  caption="500자 이내"
  rows={5}
  maxLength={500}
  {...register("bio")}
/>
```

## props

| prop           | 타입                                          | 기본값  | 설명                                  |
| -------------- | --------------------------------------------- | ------- | ------------------------------------- |
| `label`        | `ReactNode`                                   | 없음    | 레이블                                |
| `size`         | `"lg" \| "md"`                                | `"lg"`  | 글자 크기 (높이는 자동)               |
| `invalid`      | `boolean`                                     | `false` | 오류 상태                             |
| `errorMessage` | `ReactNode`                                   | 없음    | `invalid`일 때 표시                   |
| 나머지         | `ComponentPropsWithRef<"textarea">` 의 대부분 | -       | `rows`, `maxLength`, `placeholder` 등 |
