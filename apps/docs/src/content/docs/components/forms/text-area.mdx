피그마 `Text Area`를 구현했습니다. 피그마 설명대로 공지 작성 페이지처럼 장문형 텍스트를 쓰는 칸입니다. 주소처럼 짧은 글을 여러 줄로 받을 때는 [TextFieldArea](../text-field-area/)를 씁니다. 네이티브 `textarea` 속성과 `ref`를 그대로 받고, 레이블과 도움말은 [Field](../field/)와 같습니다.

```tsx
import { TextArea } from "@umc-product/react"

<TextArea
  label="공지 내용"
  placeholder="챌린저에게 전할 공지를 작성하세요"
  maxLength={1000}
  {...register("notice")}
/>
```

<TextAreaDefault client:visible />

## TextFieldArea와 다른 점

|         | TextArea                                               | TextFieldArea                              |
| ------- | ------------------------------------------------------ | ------------------------------------------ |
| 피그마  | `Text Area`                                            | `Text Field/ Input Box`의 `Type=Text Area` |
| 쓰임    | 공지처럼 긴 글                                         | 주소처럼 짧은 글                           |
| 높이    | 한 줄에서 시작해 내용에 맞춰 늘고 최대 높이부터 스크롤 | 2줄부터 시작하고 손잡이로 늘림             |
| 글자 수 | `maxLength`를 넘기면 오른쪽 아래에 표시                | 없음                                       |
| 크기    | 16px 한 가지                                           | `lg`(18px), `md`(16px)                     |

## 글자 수

`maxLength`를 넘기면 오른쪽 아래에 "현재/최대" 글자 수가 나옵니다. 최대 글자 수를 넘겨서는 입력할 수 없습니다. 비활성 상태에서도 글자 수는 그대로 보입니다.

## 높이

기본으로는 최소 높이와 최대 높이가 없어 한 줄 높이에서 시작합니다. 피그마 설명대로 최소·최대 높이는 페이지마다 달라질 수 있어서, 필요하면 `className`으로 `--umc-text-area-min-height`와 `--umc-text-area-max-height` 변수를 넘깁니다. 내용이 늘면 상자도 최대 높이까지 함께 늘어나고, 그보다 긴 내용은 상자 안에서 스크롤됩니다. 늘어나는 동작은 CSS `field-sizing`을 지원하는 브라우저에서만 일어납니다. 지원하지 않는 브라우저에서는 두 줄 높이(최소 높이를 정했으면 그 높이)에서 스크롤됩니다.

```tsx
<TextArea
  label="모집 공고 본문"
  maxLength={2000}
  className="[--umc-text-area-min-height:240px] [--umc-text-area-max-height:320px]"
/>
```

Tailwind를 쓰지 않는 앱은 CSS 클래스에서 같은 변수를 선언하고 그 클래스를 `className`으로 넘깁니다.

## 상태

피그마에는 오류 상태가 없습니다. 그래서 오류 모양은 `TextField`처럼 빨간 테두리와 배경으로 그립니다.

## 문구 규칙

피그마 설명대로 플레이스홀더 끝에는 온점(.)을 찍지 않습니다.

## props

`Field`의 props와 네이티브 `textarea` 속성을 받습니다.

| prop           | 타입        | 기본값 | 설명                                   |
| -------------- | ----------- | ------ | -------------------------------------- |
| `maxLength`    | `number`    | -      | 최대 글자 수. 넘기면 글자 수를 보여 줌 |
| `label`        | `ReactNode` | -      | 레이블                                 |
| `caption`      | `ReactNode` | -      | 도움말                                 |
| `invalid`      | `boolean`   | -      | 오류 상태                              |
| `errorMessage` | `ReactNode` | -      | 오류 문구                              |
| `disabled`     | `boolean`   | -      | 비활성                                 |
