피그마 `Search Field`(노드 2621:33450)를 구현합니다. `type="search"`를 사용하며 브라우저 기본 취소 버튼은 숨깁니다.

```tsx
import { SearchField } from "@umc-product/react"

;<SearchField
  placeholder="프로젝트 검색"
  value={query}
  onChange={(e) => setQuery(e.target.value)}
/>
```

## props

| prop          | 타입                             | 기본값 | 설명                          |
| ------------- | -------------------------------- | ------ | ----------------------------- |
| `size`        | `"lg" \| "md"`                   | `"lg"` | 높이와 글자 크기              |
| `clearable`   | `boolean`                        | `true` | 값이 있을 때 지우기 버튼 표시 |
| `placeholder` | `string`                         | 없음   | 플레이스홀더 텍스트           |
| 나머지        | `ComponentPropsWithRef<"input">` | -      | `onChange`, `value`, `ref` 등 |
