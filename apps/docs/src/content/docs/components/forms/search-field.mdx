피그마 `Search Field`를 구현했습니다. 테두리 없이 회색 배경에 놓이고, 값이 있으면 지우기 버튼이 나타납니다. 보이는 레이블이 없으므로 기본 `aria-label`은 "검색"이고, 맥락에 맞는 이름을 넘기는 편이 좋습니다.

```tsx
import { SearchField } from "@umc-product/react"

<SearchField
  aria-label="프로젝트 검색"
  placeholder="프로젝트 이름으로 검색하세요"
  onChange={(event) => setQuery(event.target.value)}
/>
```

## 기본

돋보기는 오른쪽 끝에 있습니다. 검색 실행은 폼 제출(Enter)이나 입력 변화로 처리합니다.

<SearchFieldDefault client:visible />

## 목록 위 검색

`variant="dropdown"`은 피그마 `Type=with Dropdown List`입니다. 돋보기가 왼쪽에 작게 놓이고 hover와 입력 중에 배경이 짙어집니다. `Select`의 `searchable`이 이 모양을 씁니다.

<SearchFieldDropdown client:visible />

## 모든 변형

피그마 `Search Field` 변형 5개를 그렸습니다. 칸에 마우스를 올리면 변형 이름이 보이고, hover와 포커스 같은 상태는 켜 둔 모습입니다.

<SearchFieldAllVariants client:visible />

## props

네이티브 `input` 속성을 받습니다(`type`은 `search`로 고정).

| prop        | 타입                      | 기본값      | 설명                     |
| ----------- | ------------------------- | ----------- | ------------------------ |
| `variant`   | `"default" \| "dropdown"` | `"default"` | 모양                     |
| `clearable` | `boolean`                 | `true`      | 값이 있을 때 지우기 버튼 |
