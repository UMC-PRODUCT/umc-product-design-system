피그마 `Numeric Stepper`(node 3032:89173)를 구현했습니다. 피그마 설명대로 값을 바꿀 수 있는 방향의 버튼만 켭니다. 최솟값이면 [−], 최댓값이면 [+]가 꺼집니다. 숫자는 세 자리까지 쓰므로 기본 범위는 0부터 999입니다.

```tsx
import { NumericStepper } from "@umc-product/react"

;<NumericStepper
  aria-label="Frontend 모집 인원"
  value={quota}
  onValueChange={setQuota}
/>
```

피그마 예시처럼 파트 이름 옆에 놓을 때는 `aria-label`로 이름을 붙입니다. 아래에서 Design은 0, Backend는 999라 각각 한쪽 버튼이 꺼져 있습니다.

<NumericStepperDefault client:visible />

## 비활성

두 버튼과 숫자를 모두 흐리게 표시합니다.

<NumericStepperDisabled client:visible />

## props

`Field`의 props를 받습니다.

| prop            | 타입                              | 기본값 | 설명              |
| --------------- | --------------------------------- | ------ | ----------------- |
| `value`         | `number \| null`                  | 없음   | 제어 값           |
| `defaultValue`  | `number`                          | 없음   | 비제어 초기값     |
| `onValueChange` | `(value: number \| null) => void` | 없음   | 값이 바뀔 때      |
| `min`           | `number`                          | `0`    | 최솟값            |
| `max`           | `number`                          | `999`  | 최댓값            |
| `step`          | `number`                          | `1`    | 한 번에 바뀌는 양 |
| `name`          | `string`                          | 없음   | 폼 제출 이름      |
| `aria-label`    | `string`                          | 없음   | 숫자 입력의 이름  |

## 피그마와 다른 점

- 숫자 글자는 피그마 스타일 이름이 `Label/1-Semibold`지만 값(16px, -2%)은 `Label/3-Semibold`와 같습니다. 보이는 크기를 지키려고 `Label/3-Semibold` 토큰을 썼습니다.
- 피그마 숫자 칸의 좌우 패딩 20px은 106px 너비 안에 들어가지 않아(34px 칸) 패딩 없이 가운데 정렬했습니다.
