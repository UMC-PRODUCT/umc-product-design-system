피그마 `Text Field/Line`과 그 안의 `Text Field/Line/Field`(`Type=Text`, `Type=Password`)를 구현했습니다. 테두리 상자 대신 2px 밑줄과 22px Semibold 글자를 써서 이름이나 제목처럼 한 화면에 하나뿐인 값을 크게 받을 때 씁니다. 상자 모양은 [TextFieldBox](../text-field-box/)입니다. 네이티브 `input` 속성과 `ref`를 그대로 받습니다.

```tsx
import { TextFieldLine } from "@umc-product/react"

<TextFieldLine label="프로젝트 이름" required {...register("name")} />
```

## 기본

위아래 16px 여백이 컴포넌트에 들어 있습니다(피그마 `Text Field/Line` 프레임). 레이블과 밑줄 칸, 도움말 사이는 6px입니다.

<TextFieldLineDefault client:visible />

## 값이 있을 때

값이 있으면 지우기 버튼이 나타납니다. 지우기 버튼은 탭 순서에서 빠지고, 누르면 값을 비운 뒤 입력으로 포커스를 돌려 줍니다. 캐럿은 `teal-400`으로 상자 모양(`teal-500`)보다 한 단계 옅습니다(피그마 값).

<TextFieldLineFilled client:visible />

## 비밀번호

`type="password"`이면 눈 아이콘 버튼으로 내용을 보이거나 숨깁니다. 이때는 지우기 버튼을 쓰지 않습니다.

<TextFieldLinePassword client:visible />

## 오류

피그마 `Error=True`는 밑줄을 hover와 포커스에서만 `red-500`으로 바꾸고, 평소 밑줄은 회색 그대로입니다. 레이블과 도움말은 `Field` 규칙대로 빨갛게 바뀝니다. 포커스 전에도 밑줄로 오류를 보여 줄지는 디자인 확인 목록(폼 27번)에 물어 두었습니다.

<TextFieldLineInvalid client:visible />

## 모든 변형

피그마 `Text Field/Line` 변형 10개를 그렸습니다. 칸(`Text Field/Line/Field`)의 변형 13개는 [TextFieldLineField](../text-field-line-field/#모든-변형)에 있습니다. 칸에 마우스를 올리면 코드가 보이고, hover와 포커스 같은 상태는 켜 둔 모습입니다.

<TextFieldLineAllVariants client:visible />

## props

`Field`의 props(`label`, `required`, `caption`, `captionColor`, `captionSize`, `invalid`, `errorMessage`)와 네이티브 `input` 속성을 받습니다.

| prop        | 타입      | 기본값 | 설명                     |
| ----------- | --------- | ------ | ------------------------ |
| `clearable` | `boolean` | `true` | 값이 있을 때 지우기 버튼 |

## 알아 둘 점

- 크기는 한 가지(22px)라 `size`가 없고, 단위를 붙이는 `unit`도 없습니다.
- 글자가 칸보다 길면 포커스가 없을 때 말줄임표로 줄입니다.
