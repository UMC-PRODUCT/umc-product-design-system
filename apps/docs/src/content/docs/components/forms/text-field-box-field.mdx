피그마 `Text Field/Box/Field`의 상자입니다(0.7.0까지는 `InputBox`). `TextFieldBox`, `TextFieldArea`, `VerificationCodeField`가 이 상자를 씁니다. 직접 쓰는 경우는 피그마 `Type=Custom`처럼 안쪽을 자유롭게 채울 때입니다. 밑줄 모양은 [TextFieldLineField](../text-field-line-field/)입니다.

```tsx
import { TextFieldBoxField } from "@umc-product/react"

<TextFieldBoxField size="md">
  <input className="umc-text-field-box-field__input" aria-label="앞자리" />
  <span aria-hidden="true">-</span>
  <input className="umc-text-field-box-field__input" aria-label="뒷자리" />
</TextFieldBoxField>
```

## 상태

상태는 상자 하나가 CSS로 정합니다. 마우스를 올리거나 포커스하면 테두리가 `--umc-color-border-primary-strong-500`으로 바뀌고, 값이 있는 채로 포커스하면(피그마 Typing) 배경이 옅은 청록으로 바뀝니다.

| 상태          | 테두리                                                 | 배경                                 |
| ------------- | ------------------------------------------------------ | ------------------------------------ |
| 기본          | `--umc-color-border-neutral-medium-300`                | `--umc-color-fill-neutral-default`   |
| hover, 포커스 | `--umc-color-border-primary-strong-500`                | 기본과 같음                          |
| 입력 중       | `--umc-color-border-primary-strong-500`                | `#f4fbfa99`(피그마 값)               |
| 오류          | 빈 값 red-300, hover와 포커스 red-400, 채운 값 red-500 | `#fef2f14d`(red-50 30%, 피그마 값)   |
| 비활성        | `--umc-color-border-neutral-weaker-100`                | `--umc-color-fill-neutral-weaker-50` |

`invalid`가 켜지는 순간 상자가 좌우로 흔들립니다. 동작 줄이기 설정에서는 흔들지 않습니다.

## 모든 변형

피그마 `Text Field/Box/Field`의 Custom 변형 10개와 `.primitive/ Text Field/ Accessory` 6개를 그렸습니다. 부속 요소는 그 요소가 나타나는 필드 안에 그렸습니다. 칸에 마우스를 올리면 코드가 보이고, hover와 포커스 같은 상태는 켜 둔 모습입니다.

## props

| prop       | 타입           | 기본값 | 설명                |
| ---------- | -------------- | ------ | ------------------- |
| `size`     | `"lg" \| "md"` | `"lg"` | 높이 48px 또는 44px |
| `invalid`  | `boolean`      | 없음   | 오류 상태           |
| `disabled` | `boolean`      | 없음   | 비활성 상태         |

나머지 `div` 속성은 그대로 전달합니다. 값이 있는지는 안쪽 컨트롤의 `data-filled`로 판단하므로 `FieldControl`을 쓰면 입력 중 배경이 자동으로 적용됩니다.

## 알아 둘 점

- 0.8.0에서 `InputBox`가 `TextFieldBoxField`로 바뀌었습니다. 안쪽 요소의 클래스도 `umc-input-box__input`에서 `umc-text-field-box-field__input`으로 바뀌었습니다.
