피그마 `Verification Code Field`(노드 2621:33460)를 구현합니다. `TextField`와 같은 구조에 타이머와 안내 텍스트 슬롯을 추가했습니다.

```tsx
import { VerificationCodeField } from "@umc-product/react"

;<VerificationCodeField
  label="인증번호"
  timer={<span>{formatTime(remaining)}</span>}
  infoSlot="인증번호가 발송되었습니다"
  maxLength={6}
  inputMode="numeric"
  {...register("code")}
/>
```

## props

| prop           | 타입                             | 기본값  | 설명                               |
| -------------- | -------------------------------- | ------- | ---------------------------------- |
| `label`        | `ReactNode`                      | 없음    | 레이블                             |
| `timer`        | `ReactNode`                      | 없음    | 입력 오른쪽 타이머 슬롯            |
| `infoSlot`     | `ReactNode`                      | 없음    | 필드 아래 안내 아이콘 + 텍스트     |
| `invalid`      | `boolean`                        | `false` | 오류 상태                          |
| `errorMessage` | `ReactNode`                      | 없음    | `invalid`일 때 표시                |
| 나머지         | `ComponentPropsWithRef<"input">` | -       | `maxLength`, `inputMode`, `ref` 등 |
