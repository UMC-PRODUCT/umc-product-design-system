피그마 `Text Field/ Verification Code`(node 2621:36619)를 구현했습니다. 입력 상자는 `TextField`와 같고 오른쪽에 타이머를 둡니다. 숫자 키패드(`inputMode="numeric"`)와 문자 자동 완성(`autoComplete="one-time-code"`)을 기본으로 켭니다.

```tsx
import { TextInfoButton, VerificationCodeField } from "@umc-product/react"

;<VerificationCodeField
  label="인증번호"
  placeholder="숫자 6자리"
  maxLength={6}
  timer={remainingText}
  info={<TextInfoButton onClick={resend}>인증번호 다시 받기</TextInfoButton>}
/>
```

타이머는 표시만 맡습니다. 남은 시간을 세는 일과 만료 처리는 앱에서 합니다. 아래 예시는 3분부터 1초씩 줄어듭니다.

## props

`Field`의 props와 네이티브 `input` 속성을 받습니다.

| prop        | 타입           | 기본값 | 설명                     |
| ----------- | -------------- | ------ | ------------------------ |
| `size`      | `"lg" \| "md"` | `"lg"` | 높이 48px 또는 44px      |
| `timer`     | `ReactNode`    | 없음   | 오른쪽 남은 시간         |
| `info`      | `ReactNode`    | 없음   | 아래쪽 정보 버튼 자리    |
| `clearable` | `boolean`      | `true` | 값이 있을 때 지우기 버튼 |
