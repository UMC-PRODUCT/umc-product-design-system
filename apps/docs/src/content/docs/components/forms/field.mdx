피그마 `Text Field/ Box`의 레이블(`Text Field/ Label`)과 도움말(`Help Text`) 부분입니다. `TextField`, `TextFieldArea`, `Select`, `VerificationCodeField`, `CodeField`, `NumericStepper`가 모두 이 틀을 씁니다. 직접 만든 컨트롤을 넣을 때는 `FieldControl`을 함께 씁니다.

```tsx
import { Field, FieldControl, InputBox } from "@umc-product/react"

<Field label="학교 이메일" required caption="학교 도메인만 받습니다">
  <InputBox>
    <FieldControl className="umc-input-box__input" />
  </InputBox>
</Field>
```

<FieldDefault client:visible />

## 도움말 색

`captionColor="primary"`는 피그마 `Help Text/Primary`로 초록(`--umc-color-text-success`)입니다. `invalid`이면 레이블과 도움말이 빨강으로 바뀌고, `errorMessage`가 있으면 도움말 자리를 오류 메시지가 대신합니다. 비활성이면 레이블과 도움말이 흐려집니다.

<FieldCaptionTones client:visible />

## 정보 버튼

`info`는 도움말 아래에 놓입니다. 피그마 인증번호 필드와 코드 입력 필드의 `Text Info Button` 자리입니다.

<FieldWithInfo client:visible />

## 접근성

`FieldControl`은 레이블의 `for`, `aria-describedby`, `aria-invalid`를 자동으로 연결합니다. 필수 표시 `*`는 화면 낭독기에 읽히지 않고, 대신 컨트롤에 `required`가 붙습니다.

## 모든 변형

피그마 `Text Field/ Label` 6개와 `Help Text` 4개를 그렸습니다. 칸에 마우스를 올리면 코드가 보이고, hover와 포커스 같은 상태는 켜 둔 모습입니다.

## props

| prop           | 타입                     | 기본값      | 설명                              |
| -------------- | ------------------------ | ----------- | --------------------------------- |
| `label`        | `ReactNode`              | 없음        | 레이블                            |
| `required`     | `boolean`                | 없음        | 필수 표시 `*`                     |
| `caption`      | `ReactNode`              | 없음        | 도움말                            |
| `captionColor` | `"neutral" \| "primary"` | `"neutral"` | 도움말 색                         |
| `invalid`      | `boolean`                | 없음        | 오류 상태                         |
| `errorMessage` | `ReactNode`              | 없음        | 오류일 때 도움말 대신 보일 메시지 |
| `info`         | `ReactNode`              | 없음        | 아래쪽 정보 버튼 자리             |
| `disabled`     | `boolean`                | 없음        | 비활성 상태                       |
| `nativeLabel`  | `boolean`                | `true`      | 버튼형 컨트롤이면 `false`         |
