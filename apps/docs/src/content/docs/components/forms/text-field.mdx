피그마 `Text Field/ Box`(node 2621:33350)와 `Text Field/ Input Box`의 `Type=Text`, `Type=Password`를 구현했습니다. 네이티브 `input` 속성과 `ref`를 그대로 받으므로 `react-hook-form`의 `register()` 결과를 펼쳐 넘길 수 있습니다.

```tsx
import { TextField } from "@umc-product/react"

const { register } = useForm()

<TextField label="이메일" required {...register("email")} />
```

## 기본

placeholder 끝에는 온점을 찍지 않습니다(피그마 컴포넌트 설명).

<TextFieldDefault client:visible />

## 값이 있을 때

값이 있으면 지우기 버튼이 나타납니다. 지우기 버튼은 탭 순서에서 빠지고, 누르면 값을 비운 뒤 입력으로 포커스를 돌려 줍니다. `unit`은 오른쪽 끝에 단위를 붙입니다.

<TextFieldFilled client:visible />

## 크기

<TextFieldSizes client:visible />

## 비밀번호

`type="password"`이면 눈 아이콘 버튼으로 내용을 보이거나 숨깁니다. 이때는 지우기 버튼을 쓰지 않습니다.

<TextFieldPassword client:visible />

## 오류

빈 값 오류는 연한 빨강(red-300) 테두리, 값을 채운 오류는 진한 빨강(red-500) 테두리와 빨간 글자입니다. 다시 포커스하면 글자색이 돌아오고 테두리는 red-400이 됩니다.

<TextFieldInvalid client:visible />

## 모든 변형

피그마 `Text Field/ Input Box`의 Text·Password 변형 20개와, 레이블·도움말까지 묶은 `Text Field/ Box` 변형 10개를 그렸습니다. 칸에 마우스를 올리면 피그마 변형 이름이 보입니다. Hover, Focus, Typing처럼 마우스나 키보드가 있어야 보이는 상태는 문서에서 켜 둔 모습입니다.

<TextFieldAllVariants client:visible />

## props

`Field`의 props(`label`, `required`, `caption`, `captionColor`, `invalid`, `errorMessage`)와 네이티브 `input` 속성을 받습니다.

| prop        | 타입           | 기본값 | 설명                     |
| ----------- | -------------- | ------ | ------------------------ |
| `size`      | `"lg" \| "md"` | `"lg"` | 높이 48px 또는 44px      |
| `unit`      | `ReactNode`    | 없음   | 오른쪽 단위 텍스트       |
| `clearable` | `boolean`      | `true` | 값이 있을 때 지우기 버튼 |

## 피그마와 다른 점

- Md 비밀번호 필드의 오른쪽 패딩: 피그마는 4px, 일반 Md 필드는 8px입니다. 같은 크기 안에서 오른쪽 여백이 달라지지 않도록 8px로 맞췄습니다.
- 지우기 아이콘 색 #e2e4e3은 토큰에 없어 컴포넌트 변수로 썼습니다. 오류 상태에서는 피그마대로 #cccccc입니다.
- Lg 단위 텍스트는 `Mobile Web/Label/1-Medium`(18px/24px, -3%)이라 토큰 대신 피그마 값을 썼습니다.
