피그마 `Text Field/Box`와 그 안의 `Text Field/Box/Field`(`Type=Text`, `Type=Password`)를 구현했습니다. 0.7.0까지는 `TextField`였는데, 피그마가 밑줄 모양 `Text Field/Line`을 더하면서 상자 모양을 `Text Field/Box`로 부르게 되어 이름을 따라갔습니다. 네이티브 `input` 속성과 `ref`를 그대로 받으므로 `react-hook-form`의 `register()` 결과를 펼쳐 넘길 수 있습니다.

```tsx
import { TextFieldBox } from "@umc-product/react"
import { useForm } from "react-hook-form"

const { register } = useForm()

<TextFieldBox label="이메일" required {...register("email")} />
```

## 기본

placeholder 끝에는 온점을 찍지 않습니다(피그마 컴포넌트 설명).

<TextFieldBoxDefault client:visible />

## 값이 있을 때

값이 있으면 지우기 버튼이 나타납니다. 지우기 버튼은 탭 순서에서 빠지고, 누르면 값을 비운 뒤 입력으로 포커스를 돌려 줍니다. `unit`은 오른쪽 끝에 단위를 붙입니다.

<TextFieldBoxFilled client:visible />

## 크기

<TextFieldBoxSizes client:visible />

## 비밀번호

`type="password"`이면 눈 아이콘 버튼으로 내용을 보이거나 숨깁니다. 이때는 지우기 버튼을 쓰지 않습니다.

<TextFieldBoxPassword client:visible />

## 오류

빈 값 오류는 연한 빨강(red-300) 테두리, 값을 채운 오류는 진한 빨강(red-500) 테두리와 빨간 글자입니다. 다시 포커스하면 글자색이 돌아오고 테두리는 red-400이 됩니다.

## 모든 변형

피그마 `Text Field/Box/Field`의 Text·Password 변형 20개와, 레이블·도움말까지 묶은 `Text Field/Box` 변형 10개를 그렸습니다. 칸에 마우스를 올리면 코드가 보이고, hover와 포커스 같은 상태는 켜 둔 모습입니다.

<TextFieldBoxAllVariants client:visible />

## props

`Field`의 props(`label`, `required`, `caption`, `captionColor`, `captionSize`, `invalid`, `errorMessage`)와 네이티브 `input` 속성을 받습니다.

| prop        | 타입           | 기본값 | 설명                     |
| ----------- | -------------- | ------ | ------------------------ |
| `size`      | `"lg" \| "md"` | `"lg"` | 높이 48px 또는 44px      |
| `unit`      | `ReactNode`    | 없음   | 오른쪽 단위 텍스트       |
| `clearable` | `boolean`      | `true` | 값이 있을 때 지우기 버튼 |

## 알아 둘 점

- 0.8.0에서 `TextField`가 `TextFieldBox`로, `InputBox`가 `TextFieldBoxField`로 바뀌었습니다. CSS 클래스도 `umc-input-box*`에서 `umc-text-field-box-field*`로 바뀌었습니다.
