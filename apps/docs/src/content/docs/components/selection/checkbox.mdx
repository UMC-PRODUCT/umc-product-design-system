피그마 `Check Box`를 `Checkbox`로, `Check Button`을 `CheckButton`으로 옮겼습니다. 체크 상태와 키보드 조작, 폼 제출은 Base UI `Checkbox`가 맡습니다.

```tsx
import { Checkbox } from "@umc-product/react"

<Checkbox color="brand" defaultChecked>면접 진행</Checkbox>
<Checkbox labelPlacement="end">개인정보 수집 동의</Checkbox>
<Checkbox aria-label="전체 선택" />
```

<CheckboxBasics client:visible />

## 라벨

라벨은 `children`으로 넘깁니다. 피그마 기본값처럼 라벨이 체크박스 앞에 오고, `labelPlacement="end"`면 뒤로 갑니다. 라벨과 체크박스를 함께 `<label>`로 감싸므로 라벨을 눌러도 체크가 바뀝니다. 라벨이 여러 줄이면 체크박스는 첫 줄에 맞춥니다.

체크박스만 쓰려면 `children`을 비웁니다. 피그마의 "라벨을 끄고 쓰는" 경우입니다. 이때는 화면 낭독기가 읽을 이름을 `aria-label`로 주거나, 바깥 `<label htmlFor>`와 `id`로 연결하세요.

## 상태

| 상태     | prop            | 테두리(체크 안 함)          | 채움(체크)                        |
| -------- | --------------- | --------------------------- | --------------------------------- |
| neutral  | 기본            | `border-neutral-strong-400` | `fill-neutral-inverse-strong-600` |
| brand    | `color="brand"` | `border-primary-medium-300` | `fill-primary-inverse-medium-500` |
| invalid  | `invalid`       | `border-error-strong-500`   | `red-400`                         |
| disabled | `disabled`      | `border-neutral-disabled`   | `fill-neutral-strong-200`         |

`invalid`는 `color`보다, `disabled`는 `invalid`보다 앞섭니다. `invalid`를 주면 `aria-invalid`도 붙습니다. [Field](../../forms/field/)로 감싸면 Field의 `disabled`, `invalid`도 같은 모양을 냅니다. 오류 문구는 체크박스가 그리지 않으니 주변 문구와 `aria-describedby`로 연결하세요.

## CheckButton

`CheckButton`은 상자 테두리 없이 체크만 그리는 체크박스입니다. 체크하지 않으면 회색(`teal-grey-200`), 체크하면 틸(`icon-brand-medium-500`)입니다. 화면에 라벨이 없으므로 `<label>`로 감싸거나 `aria-label`로 이름을 주세요.

```tsx
import { CheckButton } from "@umc-product/react"

<CheckButton aria-label="공지 읽음 표시" checked={read} onCheckedChange={setRead} />
```

## 모든 변형

피그마 `Check Box` 16개, 조합용 `.primitive/Check Box/Control` 16개, `Check Button` 2개를 그렸습니다. Control은 피그마 설명대로 화면에서 직접 쓰지 않는 조합용 부품이라 따로 공개하지 않습니다. 라벨을 끈 `Checkbox`가 같은 모양입니다.

## props

### Checkbox

| prop                                                | 타입                         | 기본값      | 설명                             |
| --------------------------------------------------- | ---------------------------- | ----------- | -------------------------------- |
| `checked`                                           | `boolean`                    | 없음        | 제어형 체크 상태                 |
| `defaultChecked`                                    | `boolean`                    | `false`     | 비제어형 초기 체크 상태          |
| `onCheckedChange`                                   | `(checked: boolean) => void` | 없음        | 체크가 바뀔 때 새 값             |
| `color`                                             | `"neutral" \| "brand"`       | `"neutral"` | 체크 안 함 테두리와 체크 채움 색 |
| `size`                                              | `"md" \| "lg"`               | `"md"`      | 크기                             |
| `invalid`                                           | `boolean`                    | `false`     | 오류 모양과 `aria-invalid`       |
| `disabled`                                          | `boolean`                    | `false`     | 비활성                           |
| `labelPlacement`                                    | `"start" \| "end"`           | `"start"`   | 라벨 위치                        |
| `children`                                          | `ReactNode`                  | 없음        | 라벨. 비우면 체크박스만 그림     |
| `name`, `value`, `required`, `id`, `inputRef`       |                              | 없음        | 폼 제출용. 숨은 `<input>`에 붙음 |
| `aria-label`, `aria-labelledby`, `aria-describedby` | `string`                     | 없음        | 접근성 이름과 설명               |

### CheckButton

`checked`, `defaultChecked`, `onCheckedChange`, `disabled`, `name`, `value`, `id`, `inputRef`, `aria-label`, `aria-labelledby`, `className`을 받습니다. 의미는 `Checkbox`와 같습니다.

## 알아 둘 점

- `CheckButton`에는 비활성 모양이 따로 없습니다. 비활성이어도 체크 여부에 따른 색은 그대로이고 커서만 바뀝니다.
