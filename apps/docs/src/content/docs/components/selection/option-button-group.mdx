`type="single"`(기본)이면 `RadioGroup`으로, `type="multiple"`이면 `CheckboxGroup`으로 렌더됩니다. 두 모드 모두 키보드 탐색과 ARIA 역할을 자동으로 처리합니다.

```tsx
import { OptionButtonGroup } from "@umc-product/react"

<OptionButtonGroup
  options={[
    { value: "fe", label: "프론트엔드" },
    { value: "be", label: "백엔드" },
  ]}
  aria-label="파트 선택"
  defaultValue="fe"
/>
```

## 변형

선택한 항목은 앞에 체크 아이콘이 붙습니다. `variant="weak"`(기본)는 옅은 틸 배경과 틸 테두리, `variant="strong"`은 진한 틸 배경과 흰 글자입니다. 선택하지 않은 항목끼리 붙어 있으면 1px 간격이 생겨 구분선처럼 보입니다. 피그마의 Direction(Left, Middle, Right)은 항목 순서로 정하므로 prop이 없습니다.

## 크기

| size | 높이 | 좌우 여백(선택 안 함)     | 좌우 여백(선택) | 체크 아이콘 | 글자(선택 안 함 / 선택)             |
| ---- | ---- | ------------------------- | --------------- | ----------- | ----------------------------------- |
| `xl` | 48px | 28px, 28px                | 18px, 28px      | 20px        | 20px Regular / `title-2-medium`     |
| `sm` | 38px | 20px, 20px                | 12px, 20px      | 16px        | `body-1-regular` / `label-3-medium` |
| `xs` | 28px | 12px(양 끝은 바깥쪽 14px) | 6px, 10px       | 16px        | `label-5-medium`                    |

## 제어 모드

`value`와 `onValueChange`로 외부 상태와 연결합니다. React Hook Form을 쓸 때는 `Controller`의 `field.value`를 `value`에, `field.onChange`를 `onValueChange`에 연결합니다.

## 모든 변형

피그마 `.primitive/Segmented Control/Option Button` 45개와 체크 `Check-icon` 2개, 일곱 칸짜리 `Segmented Control/Option` 7개를 그렸습니다. 버튼 하나의 변형은 세 칸짜리 그룹에서 해당 위치(Left, Middle, Right)의 버튼으로 보여 줍니다. 칸에 마우스를 올리면 피그마 변형 이름이 보입니다. Hover처럼 마우스가 있어야 보이는 상태는 문서에서 켜 둔 모습입니다.

## props

| prop            | 타입                     | 기본값     | 설명                |
| --------------- | ------------------------ | ---------- | ------------------- |
| `type`          | `"single" \| "multiple"` | `"single"` | 선택 모드           |
| `options`       | `OptionItem[]`           | 필수       | 선택 항목 목록      |
| `variant`       | `"weak" \| "strong"`     | `"weak"`   | 선택 색 강도        |
| `size`          | `"xl" \| "sm" \| "xs"`   | `"sm"`     | 버튼 크기           |
| `value`         | `string` 또는 `string[]` | 없음       | 제어 선택값         |
| `defaultValue`  | `string` 또는 `string[]` | 없음       | 비제어 초기값       |
| `onValueChange` | `(value) => void`        | 없음       | 선택 변경 핸들러    |
| `name`          | `string`                 | 없음       | form `name` 속성    |
| `aria-label`    | `string`                 | 없음       | 그룹 접근 가능 이름 |

## 디자인 팀 확인 사항

- Xl의 선택하지 않은 글자는 `Title/2-Medium`을 Regular로 바꾼 값(20px, 400)이라 텍스트 스타일이 없습니다. 지금은 역할 변수로 굵기만 바꿉니다.
- Sm 선택 글자의 자간이 컴포넌트에서는 -3%입니다. 예전에 게시된 `Label/3-Medium`을 참조한 차이로 보고 토큰 값(-2%)을 썼습니다.
- Strong이면서 Disabled인 변형이 없습니다. Button Fill Primary 비활성과 같은 색(배경 Teal-300, 글자 Teal-100)으로 가정했습니다.
- 체크는 피그마 `.primitive/Segmented Control/Check-icon`의 두 크기를 그대로 그립니다. Sm과 Xs의 16px은 따로 그린 그림이고, Xl의 20px은 `Icon/Check` Fill을 줄인 모양입니다. 두 크기를 같은 아이콘으로 맞출지 묻고 있습니다.
- 체크 아이콘 색(Weak `#008a80`, Strong `#f4fbfa`)이 글자색과 다릅니다. 의도한 차이인지 알려 주세요.
- 문서에 적힌 배경 "Teal Gray 150"은 3기 팔레트에 없고, 컴포넌트에는 `#eff0f0`(`fill-neutral-medium`)이 칠해져 있습니다.
