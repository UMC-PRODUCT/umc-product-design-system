피그마 `Radio Button`(노드 3600:96628)을 `RadioGroup`과 `Radio`로 옮겼습니다. 하나만 고르는 상태와 화살표 키 이동, 폼 제출은 Base UI `RadioGroup`이 맡습니다.

<Aside type="caution" title="쓰기 전에">
  피그마 설명은 "Form 형식 제외, 사용 지양"입니다. 단일 선택이어도 되도록 [Checkbox](/components/selection/checkbox/)나 [OptionButtonGroup](/components/selection/option-button-group/)을 쓰라고 합니다(절대 규칙은 아님). 라벨이 붙은 라디오 본체는 피그마가 "Form 형태와 함께 제작 예정"이라 아직 없습니다. 지금은 컨트롤만 제공하고 라벨은 앱이 붙입니다.
</Aside>

```tsx
import { Radio, RadioGroup } from "@umc-product/react"

<RadioGroup aria-label="모집 유형" value={type} onValueChange={setType}>
  <label className="inline-flex items-center gap-2">
    <Radio value="regular" />
    정규 모집
  </label>
  <label className="inline-flex items-center gap-2">
    <Radio value="extra" />
    추가 모집
  </label>
</RadioGroup>
```

## 라벨 붙이기

`Radio`는 원 하나만 그립니다. 각 `Radio`를 `<label>`로 감싸면 라벨을 눌러도 고를 수 있고 화면 낭독기가 라벨을 이름으로 읽습니다. 라벨을 화면에 두지 않으면 `aria-label`을 주세요. `RadioGroup`은 항목을 세로 목록으로 놓고 8px 간격을 둡니다. 피그마 설명의 "리스트 형식"을 따른 기본값이라, 가로로 놓으려면 `className`으로 바꿉니다.

## 상태

| 상태    | prop              | 테두리                      | 채움                   | 가운데 점                          |
| ------- | ----------------- | --------------------------- | ---------------------- | ---------------------------------- |
| neutral | 기본              | `border-neutral-strong-400` | `fill-neutral-default` | 없음                               |
| primary | `color="primary"` | `teal-400`                  | `fill-neutral-default` | 없음                               |
| 선택    | 그룹 값과 같음    | `teal-400`                  | `fill-neutral-default` | `icon-brand-medium-500` 12px       |
| 비활성  | `disabled`        | `border-neutral-disabled`   | `fill-neutral-weak-75` | 선택이면 `fill-neutral-strong-200` |

## props

### RadioGroup

| prop                                                | 타입                      | 기본값  | 설명                                 |
| --------------------------------------------------- | ------------------------- | ------- | ------------------------------------ |
| `value`                                             | `string \| null`          | 없음    | 제어형 선택 값. `null`이면 선택 없음 |
| `defaultValue`                                      | `string \| null`          | 없음    | 비제어형 초기 선택 값                |
| `onValueChange`                                     | `(value: string) => void` | 없음    | 선택이 바뀔 때 새 값                 |
| `disabled`                                          | `boolean`                 | `false` | 그룹 전체 비활성                     |
| `name`, `required`                                  |                           | 없음    | 폼 제출용                            |
| `children`                                          | `ReactNode`               | 필수    | `Radio`와 라벨                       |
| `aria-label`, `aria-labelledby`, `aria-describedby` | `string`                  | 없음    | 그룹 이름과 설명                     |

### Radio

| prop                            | 타입                     | 기본값      | 설명                         |
| ------------------------------- | ------------------------ | ----------- | ---------------------------- |
| `value`                         | `string`                 | 필수        | 이 항목을 고를 때 그룹 값    |
| `color`                         | `"neutral" \| "primary"` | `"neutral"` | 선택 전 테두리 색            |
| `disabled`                      | `boolean`                | `false`     | 이 항목만 비활성             |
| `aria-label`, `aria-labelledby` | `string`                 | 없음        | 라벨을 감싸지 않을 때의 이름 |

## 피그마와 다른 점

- 피그마에는 Neutral 선택 변형이 없습니다. 선택하면 `color`와 관계없이 Primary 선택 모양을 씁니다.
- 원 모서리는 피그마 9999px 리터럴 대신 모양이 같은 `radius-full` 토큰을 씁니다.
- 테두리는 `border` 대신 inset 그림자로 그립니다. 브라우저는 1.5px, 1.8px 같은 테두리 두께를 장치 픽셀 단위로 내려서 피그마보다 얇게 그리기 때문입니다(1배율 화면에서 1px).
- 포커스 상태가 없어 다른 컨트롤과 같은 2px `border-primary-strong-500` 외곽선을 넣었습니다.
