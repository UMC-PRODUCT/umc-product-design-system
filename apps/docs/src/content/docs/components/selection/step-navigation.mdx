피그마 `Web/Step Navigation`(노드 2581:16139)을 옮긴 컴포넌트입니다. Segmented Control과 같은 틀에 숫자 배지와 단계 이름을 놓고, 현재 단계만 흰 배경으로 띄웁니다. 현재 단계에는 `aria-current="step"`이 붙습니다. 단계는 눌러서 이동하지 않으며, 이동은 상위 컴포넌트가 `currentStep`을 바꿔서 처리합니다.

```tsx
import { StepNavigation } from "@umc-product/react"

;<StepNavigation
  steps={["기본 정보", "모집 문항", "미리보기"]}
  currentStep={1}
  aria-label="등록 단계"
/>
```

## props

| prop          | 타입          | 기본값 | 설명                      |
| ------------- | ------------- | ------ | ------------------------- |
| `steps`       | `ReactNode[]` | 필수   | 단계 이름 배열            |
| `currentStep` | `number`      | 필수   | 현재 단계 번호(1부터)     |
| `aria-label`  | `string`      | 없음   | 네비게이션 접근 가능 이름 |
| `className`   | `string`      | 없음   | 루트 요소에 추가할 클래스 |

## 디자인 팀 확인 사항

- 현재 단계의 그림자가 Segmented Control 선택 항목과 같은 이름 없는 값이라 역할 변수에 피그마 값을 그대로 담았습니다.
- 완료한 단계와 남은 단계의 모양 차이가 없습니다. 완료 표시(체크 아이콘 등)가 필요한지 알려 주세요.
