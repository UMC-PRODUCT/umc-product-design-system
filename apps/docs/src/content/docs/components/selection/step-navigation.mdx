현재 단계에 `aria-current="step"`을 달아 화면 낭독기에서도 단계 위치를 인식합니다. 탭 클릭으로 이동하는 기능은 없습니다. 단계 이동은 상위 컴포넌트가 `currentStep`을 갱신하는 방식으로 처리합니다.

```tsx
import { StepNavigation } from "@umc-product/react"

;<StepNavigation
  steps={["지원서 작성", "제출 확인", "결과 안내"]}
  currentStep={1}
  aria-label="지원 단계"
/>
```

## props

| prop          | 타입       | 기본값 | 설명                      |
| ------------- | ---------- | ------ | ------------------------- |
| `steps`       | `string[]` | 필수   | 단계 이름 배열            |
| `currentStep` | `number`   | 필수   | 현재 단계 인덱스(0부터)   |
| `aria-label`  | `string`   | 없음   | 네비게이션 접근 가능 이름 |
| `className`   | `string`   | 없음   | 루트 요소에 추가할 클래스 |
