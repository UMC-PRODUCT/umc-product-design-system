피그마 `Switch`를 옮겼습니다. 누르는 즉시 적용되는 설정에 씁니다. 저장 버튼을 눌러야 반영되는 폼 항목이라면 [Checkbox](../checkbox/)가 맞습니다. 켜짐 상태와 키보드 조작, 폼 제출은 Base UI `Switch`가 맡습니다.

```tsx
import { Switch } from "@umc-product/react"

<Switch checked={notify} onCheckedChange={setNotify}>알림 받기</Switch>
<Switch labelPlacement="end" size="md">면접 진행</Switch>
<Switch aria-label="다크 모드" />
```

## 라벨

피그마 설명대로 라벨을 켜고 끌 수 있습니다. 라벨은 `children`으로 넘기고 기본 위치는 스위치 앞입니다. `labelPlacement="end"`면 뒤로 갑니다. 라벨 없이 쓰면 `aria-label`로 이름을 주세요.

## 상태와 크기

| size | 트랙  | 손잡이(꺼짐 → 켜짐) | 라벨                   | 최소 높이 |
| ---- | ----- | ------------------- | ---------------------- | --------- |
| `sm` | 36×20 | 14px → 16px         | `body-2-regular`(15px) | 24px      |
| `md` | 44×24 | 16px → 20px         | `body-1-regular`(16px) | 26px      |

켜지면 손잡이가 커지면서 오른쪽 끝에서 2px 안쪽으로 옮겨 갑니다. 꺼진 손잡이는 Sm 3px, Md 4px 안쪽에 있습니다. 트랙은 꺼짐 `fill-neutral-strong-200`, 켜짐 `fill-primary-inverse-weak-400`이고, 비활성이면 각각 `fill-neutral-disabled`, `fill-primary-strong-200`입니다.

## props

| prop                                                | 타입                         | 기본값    | 설명                             |
| --------------------------------------------------- | ---------------------------- | --------- | -------------------------------- |
| `checked`                                           | `boolean`                    | 없음      | 제어형 켜짐 상태                 |
| `defaultChecked`                                    | `boolean`                    | `false`   | 비제어형 초기 상태               |
| `onCheckedChange`                                   | `(checked: boolean) => void` | 없음      | 켜짐이 바뀔 때 새 값             |
| `size`                                              | `"sm" \| "md"`               | `"sm"`    | 크기. 피그마 기본 변형이 Sm      |
| `disabled`                                          | `boolean`                    | `false`   | 비활성                           |
| `labelPlacement`                                    | `"start" \| "end"`           | `"start"` | 라벨 위치                        |
| `children`                                          | `ReactNode`                  | 없음      | 라벨. 비우면 스위치만 그림       |
| `name`, `value`, `required`, `id`, `inputRef`       |                              | 없음      | 폼 제출용. 숨은 `<input>`에 붙음 |
| `aria-label`, `aria-labelledby`, `aria-describedby` | `string`                     | 없음      | 접근성 이름과 설명               |

## 알아 둘 점

- 켜고 끌 때 손잡이가 150ms 동안 움직이고, 움직임 줄이기 설정에서는 바로 바뀝니다.
