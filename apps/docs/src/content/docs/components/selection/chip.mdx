피그마 `Chip`을 `<button>`으로 옮겼습니다. 선택·해제를 토글하거나 드롭다운을 여는 두 가지 역할로 씁니다. `DraggableChip`은 드래그 핸들이 달린 `<div>`로, 드래그 앤 드롭 목록의 항목에 씁니다.

```tsx
import { Chip, DraggableChip } from "@umc-product/react"

<Chip selected={selected} onClick={() => setSelected((s) => !s)}>
  정규 모집
</Chip>

<DraggableChip>지원서 문항</DraggableChip>
```

## 토글로 쓰기

`selected`와 `onClick`을 같이 주면 선택·해제를 토글합니다. `selected`가 있으면 `aria-pressed`를 붙이고, `aria-haspopup`이 있으면 붙이지 않습니다.

```tsx
import { useState } from "react"
import { Chip } from "@umc-product/react"

function FilterChip() {
  const [selected, setSelected] = useState(false)
  return (
    <Chip selected={selected} onClick={() => setSelected((s) => !s)}>
      정규 모집
    </Chip>
  )
}
```

## 메뉴 트리거로 쓰기

`aria-haspopup`을 주면 `aria-pressed`를 붙이지 않습니다. `Menu`의 `trigger`로 넘기면 Base UI가 열림·닫힘 상태를 관리합니다.

```tsx
import { ExpandMoreIcon } from "@umc-product/icons"
import { Chip, Menu } from "@umc-product/react"

<Menu
  trigger={
    <Chip trailingIcon={<ExpandMoreIcon weight="fill" />} aria-haspopup="menu">
      파트 선택
    </Chip>
  }
  items={[
    { label: "기획" },
    { label: "디자인" },
    { label: "프론트엔드" },
    { label: "백엔드" },
  ]}
/>
```

## 아이콘 넣기

`leadingIcon`, `trailingIcon`에 아이콘을 넘기면 크기(18px)와 아이콘 쪽 여백을 칩이 맞춥니다. 아이콘 색은 칩 상태를 따르고, 화면 낭독기에서는 숨깁니다. 피그마 칩은 `Icon/Expand_more`의 Fill 굵기를 줄여 넣었으니, 같은 모양을 내려면 아이콘에 `weight="fill"`을 넘깁니다.

## 드래그 앤 드롭에 붙이기

`DraggableChip`은 핸들 아이콘과 모양만 그리고, 끌기 동작은 앱의 드래그 라이브러리가 맡습니다. 라이브러리가 주는 `ref`, `style`, 속성, 이벤트 핸들러를 그대로 넘깁니다. 아래는 dnd-kit의 `useSortable`과 함께 쓰는 예입니다.

```tsx
import { useSortable } from "@dnd-kit/sortable"
import { CSS } from "@dnd-kit/utilities"
import { DraggableChip } from "@umc-product/react"

function SortableQuestion({ id, label }: { id: string; label: string }) {
  const { attributes, listeners, setNodeRef, transform, transition } =
    useSortable({ id })
  return (
    <DraggableChip
      ref={setNodeRef}
      style={{ transform: CSS.Transform.toString(transform), transition }}
      {...attributes}
      {...listeners}
    >
      {label}
    </DraggableChip>
  )
}
```

`useSortable`의 `attributes`에는 `tabIndex`, `role`, `aria-roledescription`이 들어 있어 키보드로도 순서를 바꿀 수 있습니다.

## props

### Chip

| prop           | 타입                              | 기본값     | 설명                                                        |
| -------------- | --------------------------------- | ---------- | ----------------------------------------------------------- |
| `variant`      | `"weak" \| "fill"`                | `"weak"`   | 외형. `weak`은 테두리 있음, `fill`은 배경 채움              |
| `color`        | `"brand" \| "neutral"`            | `"brand"`  | 색. 선택 시 강조 색을 바꿈                                  |
| `size`         | `"sm" \| "md"`                    | `"sm"`     | 높이. `sm`=34px, `md`=38px                                  |
| `selected`     | `boolean`                         | 없음       | 선택 상태. 전달하면 `aria-pressed`와 `data-selected`를 붙임 |
| `leadingIcon`  | `ReactNode`                       | 없음       | 텍스트 앞 아이콘 슬롯. `aria-hidden` 래퍼로 감쌈            |
| `trailingIcon` | `ReactNode`                       | 없음       | 텍스트 뒤 아이콘 슬롯. `aria-hidden` 래퍼로 감쌈            |
| `type`         | `"button" \| "submit" \| "reset"` | `"button"` | 네이티브 버튼 타입                                          |
| `disabled`     | `boolean`                         | `false`    | 비활성                                                      |
| `className`    | `string`                          | 없음       | 추가 클래스                                                 |
| `ref`          | `Ref<HTMLButtonElement>`          | 없음       | 버튼 엘리먼트 참조                                          |

그 밖에 네이티브 `<button>` 속성을 모두 받습니다. 단, 네이티브 `color` 속성은 `variant`·`color` prop과 충돌하므로 제외했습니다.

### DraggableChip

| prop        | 타입                   | 기본값    | 설명                                         |
| ----------- | ---------------------- | --------- | -------------------------------------------- |
| `variant`   | `"weak" \| "fill"`     | `"weak"`  | 외형. `weak`은 연한 배경, `fill`은 진한 배경 |
| `color`     | `"brand" \| "neutral"` | `"brand"` | 색                                           |
| `className` | `string`               | 없음      | 추가 클래스                                  |
| `ref`       | `Ref<HTMLDivElement>`  | 없음      | div 엘리먼트 참조                            |

그 밖에 네이티브 `<div>` 속성을 모두 받습니다. 드래그 라이브러리의 속성과 이벤트 핸들러도 이 경로로 넘깁니다.

## 알아 둘 점

- `selected`를 전달하지 않으면 `aria-pressed`가 붙지 않습니다. 드롭다운 트리거처럼 선택 상태가 없는 칩에는 `selected`를 주지 마세요.
- `aria-haspopup`이 있으면 `aria-pressed`를 붙이지 않습니다. 드롭다운 트리거에 `selected`를 같이 줘도 접근성 속성이 충돌하지 않습니다.
- 아이콘 슬롯은 `aria-hidden`으로 감쌉니다. 아이콘이 의미를 전달해야 한다면 `aria-label`로 칩 전체에 이름을 주세요.
- `DraggableChip`은 `<div>`입니다. 드래그 라이브러리를 쓰지 않고 직접 끌기를 만들면 `tabIndex`, `role`, `aria-roledescription`과 키보드 조작도 앱에서 붙입니다.
- 비활성(`disabled`)과 키보드 포커스 표시는 Button 등 다른 컴포넌트와 같은 모양입니다.
