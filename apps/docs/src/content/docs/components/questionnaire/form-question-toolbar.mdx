피그마 `Form/Question Toolbar`와 `.primitive/Form/Question Type List`를 구현했습니다. 접힌 툴바에는 더하기 버튼([FloatingActionButton](../../actions/floating-action-button/))만 있습니다. 버튼을 누르면 왼쪽에 질문 유형 버튼이 열리고 더하기 버튼은 닫기로 바뀝니다. 유형을 누르면 `onTypeSelect`가 그 값을 넘깁니다. 새 질문을 만들고 그 질문으로 포커스를 옮기는 일은 앱이 맡습니다.

```tsx
import { CheckboxIcon, RadioIcon, TextLineIcon } from "@umc-product/icons"
import { FormQuestionToolbar } from "@umc-product/react"

const questionTypes = [
  { value: "short", label: "주관식", icon: <TextLineIcon weight="fill" /> },
  { value: "single", label: "단일 선택", icon: <RadioIcon /> },
  { value: "multiple", label: "복수 선택", icon: <CheckboxIcon /> },
]

<FormQuestionToolbar items={questionTypes} onTypeSelect={addQuestion} />
```

<FormQuestionToolbarDefault client:visible />

툴바의 유형 버튼은 질문을 더하는 동작 버튼이라 고른 표시가 없습니다. 같은 유형을 연달아 눌러도 누를 때마다 `onTypeSelect`가 불립니다. 지금 유형을 보여 주고 바꾸는 목록은 아래 `FormQuestionTypeList`입니다.

## 유형 목록은 앱이 넘깁니다

어떤 질문 유형을 둘지는 서비스마다 다릅니다. 지원서에는 포트폴리오 질문이 있고, 설문에는 없을 수 있습니다. 그래서 디자인 시스템은 유형을 정해 두지 않고 `items`로 받습니다. 항목마다 값(`value`), 라벨(`label`), 아이콘(`icon`)을 넘깁니다. 피그마가 쓰는 아이콘은 아래와 같습니다.

| 유형           | 아이콘                      |
| -------------- | --------------------------- |
| 주관식, 장문형 | `TextLineIcon`, `fill` 굵기 |
| 단일 선택      | `RadioIcon`                 |
| 복수 선택      | `CheckboxIcon`              |
| 파일 업로드    | `CloudUploadIcon`           |
| 포트폴리오     | `FileUploadIcon`            |

## 질문 유형 바꾸기

`FormQuestionTypeList`는 툴바 안의 유형 목록을 따로 쓰는 컴포넌트입니다. 편집 중인 질문 아래에 두면 지금 유형에 고른 표시가 붙고, 다른 유형을 누르면 그 값을 넘깁니다. 이미 고른 유형을 다시 눌러도 선택이 풀리지 않습니다. [FormQuestionEditor](../form-question-editor/)의 `toolbar`에 넣어 씁니다.

<FormQuestionTypeListDefault client:visible />

## 키보드

- 더하기 버튼은 `aria-expanded`로 유형 버튼이 열렸는지 알립니다. 열린 동안에는 `aria-controls`로 유형 버튼 묶음을 가리킵니다.
- 더하기 버튼으로 열면 첫 유형 버튼으로 포커스가 옮겨 갑니다. 화살표 키로 유형을 옮기고 Enter나 Space로 누릅니다.
- `FormQuestionTypeList`도 Tab으로 들어간 뒤 화살표 키로 옮깁니다. 고른 유형은 눌림 상태(`aria-pressed`)로 읽힙니다.

## 모든 변형

피그마 `Form/Question Toolbar` 변형 2개와 `.primitive/Form/Question Type Item` 변형 2개를 그렸습니다. 항목 하나만 그리는 컴포넌트가 없어서, 항목 변형은 항목이 하나뿐인 목록으로 그렸습니다.

## props

### FormQuestionToolbar

| prop           | 타입                       | 기본값             | 설명                    |
| -------------- | -------------------------- | ------------------ | ----------------------- |
| `items`        | `FormQuestionTypeOption[]` | 필수               | 질문 유형 목록          |
| `open`         | `boolean`                  | 없음               | 목록을 열지(제어)       |
| `defaultOpen`  | `boolean`                  | `false`            | 처음에 열지(비제어)     |
| `onOpenChange` | `(open: boolean) => void`  | 없음               | 더하기·닫기를 누를 때   |
| `onTypeSelect` | `(value: string) => void`  | 없음               | 유형 버튼을 누를 때     |
| `openLabel`    | `string`                   | `"질문 추가"`      | 접혔을 때 버튼 이름     |
| `closeLabel`   | `string`                   | `"질문 유형 닫기"` | 열렸을 때 버튼 이름     |
| `disabled`     | `boolean`                  | `false`            | 버튼과 목록 비활성      |
| `className`    | `string`                   | 없음               | 루트 요소에 붙일 클래스 |

### FormQuestionTypeList

| prop              | 타입                       | 기본값        | 설명                   |
| ----------------- | -------------------------- | ------------- | ---------------------- |
| `items`           | `FormQuestionTypeOption[]` | 필수          | 질문 유형 목록         |
| `value`           | `string \| null`           | 없음          | 고른 유형(제어)        |
| `defaultValue`    | `string \| null`           | `null`        | 처음 고른 유형(비제어) |
| `onValueChange`   | `(value: string) => void`  | 없음          | 다른 유형을 고를 때    |
| `disabled`        | `boolean`                  | `false`       | 목록 비활성            |
| `aria-label`      | `string`                   | `"질문 유형"` | 목록 이름              |
| `id`, `className` | `string`                   | 없음          | 루트 요소에 붙음       |

```ts
import type { ReactNode } from "react"

type FormQuestionTypeOption = {
  value: string
  label: ReactNode
  icon: ReactNode
}
```

## 알아 둘 점

- 좁은 화면에서는 유형 묶음이 부모 폭에 맞춰 줄고 가로로 스크롤됩니다.
- 항목은 64px 정사각형이고 라벨은 11px(`label-7-medium`)입니다. 라벨이 길면 칸을 넘치니 다섯 글자 안팎으로 씁니다.
- 펼친 툴바의 닫기 아이콘은 피그마에서 팔레트에 없는 색(#544F4B)입니다. 코드는 더하기 아이콘과 같은 회색을 씁니다.
