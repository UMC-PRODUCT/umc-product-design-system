피그마 `Web/Form/Sheet`와 `Form/Header`를 구현했습니다. `FormHeader`는 썸네일, 제목, 부제목을 탭 모양 머리로 보여 주고, `FormSheet`는 그 머리 아래에 설명, 질문, 조작 버튼을 순서대로 놓습니다. 지원자가 작성하는 화면과 제출한 답을 조회하는 화면 모두 같은 틀을 쓰고, 안에 넣는 질문의 모드(응답, 읽기 전용)만 다릅니다.

```tsx
import { FormHeader, FormSheet } from "@umc-product/react"

<FormSheet
  header={<FormHeader title="UMC 10기 지원서" subtitle="Web" thumbnail={<img alt="" src={logo} />} />}
  description={<p>{project.summary}</p>}
  control={<Button size="md">다음</Button>}
>
  <FormSection title="기본 문항">{questions}</FormSection>
</FormSheet>
```

## 작성 화면

질문은 응답 모드로 넣고, 아래 조작 칸에는 다음 단계로 가는 버튼을 둡니다. 오른쪽 위 `action`에는 새 창으로 여는 아이콘 버튼처럼 한 장 전체에 걸리는 조작을 둡니다.

<FormSheetEditable client:visible />

## 조회 화면

같은 틀에 질문을 읽기 전용으로 넣습니다. 머리의 `caption`에는 제출 시각과 상태 태그처럼 지원서의 상태를 적습니다(피그마 `Form/Header`의 `Caption=True`). 읽기 전용 답 칸은 글자 수를 그리지 않습니다.

<FormSheetReadOnly client:visible />

## 모든 변형

피그마 `Form/Header` 변형 2개를 그렸습니다. `Web/Form/Sheet`는 변형이 없어 위 두 화면으로 대신합니다.

<FormHeaderAllVariants client:visible />

## props

### FormSheet

나머지 `section` 속성과 `ref`는 루트 요소에 붙습니다.

| prop          | 타입        | 기본값 | 설명                                             |
| ------------- | ----------- | ------ | ------------------------------------------------ |
| `header`      | `ReactNode` | 필수   | 맨 위 머리. 보통 `FormHeader`                    |
| `action`      | `ReactNode` | 없음   | 오른쪽 위 24px 줄에 놓는 아이콘 버튼             |
| `description` | `ReactNode` | 없음   | 질문 위 설명 칸(피그마 Description Slot)         |
| `children`    | `ReactNode` | 필수   | 질문 칸(피그마 Form Slot)                        |
| `control`     | `ReactNode` | 없음   | 맨 아래 오른쪽 정렬 조작 칸(피그마 Control Slot) |

### FormHeader

나머지 `div` 속성과 `ref`는 루트 요소에 붙습니다.

| prop        | 타입                    | 기본값 | 설명                                              |
| ----------- | ----------------------- | ------ | ------------------------------------------------- |
| `title`     | `ReactNode`             | 필수   | 제목(`title-2-semibold`)                          |
| `subtitle`  | `ReactNode`             | 없음   | 부제목(`body-2-medium`)                           |
| `thumbnail` | `ReactNode`             | 없음   | 50px 네모 칸에 넣을 이미지나 로고. 없으면 회색 칸 |
| `caption`   | `ReactNode`             | 없음   | 오른쪽 24px 줄에 놓는 상태 글과 태그              |
| `level`     | `2 \| 3 \| 4 \| 5 \| 6` | `2`    | 제목 단계                                         |

## 알아 둘 점

- 너비는 부모를 따릅니다. 피그마는 1000px이고, 머리의 탭은 392px보다 좁아지지 않다가 부모가 그보다 좁으면 같이 줄어듭니다.
- 피그마는 오른쪽 위 아이콘 버튼 줄(24px)이 늘 있지만, 코드는 `action`을 넘길 때만 그립니다.
- 부제목 색 `#656b6b`는 토큰에 없어 `text-neutral-medium-600`(`#606262`)을 썼습니다.
- 머리 오른쪽 곡선은 피그마 벡터를 그대로 옮긴 SVG이고, 얇은 띠는 곡선 뒤로 57px 겹쳐 틈이 생기지 않게 했습니다.
