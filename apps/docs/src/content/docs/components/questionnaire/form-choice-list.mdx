피그마 `Form/Radio Button Option List`와 `Form/Check Box Option List`의 응답 모드를 구현했습니다. `type="single"`이면 라디오로 하나를 고르고, `type="multiple"`이면 체크박스로 여러 개를 고릅니다. 고른 줄은 연한 청록 배경에 굵은 브랜드색 글자로 바뀝니다. [FormQuestion](../form-question/) 안에 넣으면 질문 제목이 목록의 이름이 됩니다. 보기를 쓰고 더하는 편집 모드는 [FormChoiceListEditor](../form-choice-list-editor/)입니다.

```tsx
import { FormChoiceList, FormQuestion } from "@umc-product/react"

<FormQuestion number="03" title="지원 파트를 골라 주세요" required>
  <FormChoiceList
    type="single"
    options={parts}
    value={part}
    onValueChange={setPart}
  />
</FormQuestion>
```

<FormChoiceListSingle client:visible />

## 여러 개 고르기

`type="multiple"`이면 `value`, `defaultValue`, `onValueChange`가 문자열 배열을 주고받습니다. 고른 보기만 브랜드색 체크박스로 바뀝니다.

<FormChoiceListMultiple client:visible />

## 고를 수 없는 보기

보기에 `disabled: true`를 주면 그 줄만 흐려지고 고를 수 없습니다. 목록 전체를 막을 때는 `disabled`를, 고른 결과를 보여 주기만 할 때는 `readOnly`를 줍니다. 둘 다 질문(`FormQuestion`)에 주면 목록이 따라갑니다.

<FormChoiceListDisabledOption client:visible />

## 키보드

- 단일 선택은 Tab으로 목록에 들어간 뒤 화살표 키로 보기를 옮기며 고릅니다.
- 복수 선택은 Tab으로 보기 사이를 옮기고 Space로 체크합니다.

## props

| prop              | 타입                             | 기본값           | 설명                        |
| ----------------- | -------------------------------- | ---------------- | --------------------------- |
| `type`            | `"single" \| "multiple"`         | 필수             | 하나 고르기, 여러 개 고르기 |
| `options`         | `FormChoiceOption[]`             | 필수             | 보기 목록                   |
| `value`           | `string \| null` 또는 `string[]` | 없음             | 고른 값(제어)               |
| `defaultValue`    | `value`와 같은 타입              | `null` 또는 `[]` | 처음 고른 값(비제어)        |
| `onValueChange`   | `(value) => void`                | 없음             | 고른 값이 바뀔 때           |
| `name`            | `string`                         | 없음             | 폼 제출에 쓸 이름           |
| `disabled`        | `boolean`                        | 질문 값          | 목록 전체 비활성            |
| `readOnly`        | `boolean`                        | 질문 값          | 고른 결과만 보여 줌         |
| `aria-label`      | `string`                         | 없음             | 질문 밖에서 쓸 때 목록 이름 |
| `aria-labelledby` | `string`                         | 질문 제목        | 목록의 이름                 |
| `className`       | `string`                         | 없음             | 루트 요소에 붙일 클래스     |

```ts
import type { ReactNode } from "react"

type FormChoiceOption = {
  value: string
  label: ReactNode
  disabled?: boolean
}
```
