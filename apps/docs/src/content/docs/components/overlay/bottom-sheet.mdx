`BottomSheet`로 시트를 열고, `BottomSheetActions`로 버튼 영역 레이아웃을 고릅니다. Base UI Drawer를 내부적으로 씁니다.

```tsx
import { BottomSheet, BottomSheetActions } from "@umc-product/react"

<BottomSheet
  trigger={<button>열기</button>}
  title="시트 제목"
  description="시트 설명입니다."
  actions={
    <BottomSheetActions
      layout="full"
      primary={{ label: "확인", onClick: () => {} }}
    />
  }
>
  <p>본문 내용</p>
</BottomSheet>
```

## Title 타입

제목과 설명을 왼쪽 정렬합니다.

<BottomSheetInteractiveTitle client:visible />

## Center 타입

`titleAlign="center"`로 제목을 가운데 정렬합니다. `headerAction`으로 오른쪽 상단에 아이콘 버튼 등을 배치할 수 있습니다.

<BottomSheetInteractiveCenter client:visible />

## 동작

- 시트를 아래로 쓸어 내리면 닫힙니다. 조금만 내렸다 놓으면 제자리로 돌아갑니다.
- 시트 바깥의 딤 영역을 누르거나 Esc를 누르면 닫힙니다.
- 열려 있는 동안 뒤 화면은 터치로 스크롤되지 않습니다. 본문이 길면 시트 안에서 스크롤됩니다.
- 시트 안의 입력칸에 포커스가 가면 가상 키보드 높이만큼 시트를 올려 입력칸이 가려지지 않게 합니다.

## 버튼 영역 레이아웃

`BottomSheetActions`는 5가지 레이아웃을 지원합니다. `full`만 `secondary`가 없고, 나머지는 `primary`와 `secondary`가 모두 필요합니다. 버튼은 모두 48px 높이의 md 크기입니다.

<BottomSheetActionsAll client:visible />

| layout        | 버튼 배치                        |
| ------------- | -------------------------------- |
| `full`        | 주요 버튼 하나, 가득 채움        |
| `stacked`     | 주요 위·보조 아래, 세로 배치     |
| `equal`       | 보조 왼쪽·주요 오른쪽, 동일 너비 |
| `emphasis`    | 3칸 중 보조 1칸·주요 2칸         |
| `primary-top` | 주요 위·흰 보조 버튼 아래 가운데 |

## props

### BottomSheet

| prop           | 타입                      | 기본값    | 설명                                 |
| -------------- | ------------------------- | --------- | ------------------------------------ |
| `children`     | `ReactNode`               | 필수      | 시트 본문 콘텐츠                     |
| `title`        | `ReactNode`               | -         | 시트 제목                            |
| `description`  | `ReactNode`               | -         | 제목 아래 설명 문구                  |
| `titleAlign`   | `"start" \| "center"`     | `"start"` | 제목 정렬 방향                       |
| `headerAction` | `ReactNode`               | -         | 헤더 오른쪽 상단 영역 (닫기 버튼 등) |
| `actions`      | `ReactNode`               | -         | 시트 하단 버튼 영역                  |
| `trigger`      | `ReactElement`            | -         | 시트를 여는 트리거 요소              |
| `open`         | `boolean`                 | -         | 제어 모드에서 열림 상태              |
| `defaultOpen`  | `boolean`                 | -         | 비제어 모드 초기 상태                |
| `onOpenChange` | `(open: boolean) => void` | -         | 열림 상태 변경 콜백                  |
| `className`    | `string`                  | -         | 팝업 루트에 추가할 CSS 클래스        |

### BottomSheetActions

| prop        | 타입                                                            | 기본값           | 설명               |
| ----------- | --------------------------------------------------------------- | ---------------- | ------------------ |
| `layout`    | `"full" \| "stacked" \| "equal" \| "emphasis" \| "primary-top"` | 필수             | 버튼 배치 레이아웃 |
| `primary`   | `{ label: ReactNode; onClick?: () => void }`                    | 필수             | 주요 버튼 설정     |
| `secondary` | `{ label: ReactNode; onClick?: () => void }`                    | `full` 이외 필수 | 보조 버튼 설정     |
