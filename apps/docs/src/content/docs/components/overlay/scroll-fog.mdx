피그마 `Scroll Fog`(노드 2596:23214)를 옮겼습니다. 스크롤 영역의 한쪽 가장자리에 74px 폭의 띠로 붙어서, 투명에서 배경색으로 바뀌며 내용이 더 있다는 것을 알려 줍니다. 부모에 `position: relative`가 필요하고, `pointer-events: none`이라 클릭과 스크롤을 막지 않습니다. 언제 보일지는 앱이 스크롤 위치를 보고 정합니다.

```tsx
import { ScrollFog } from "@umc-product/react"

;<div className="relative overflow-hidden">
  <ul className="flex overflow-x-auto">
    {items.map((item) => (
      <li key={item.id}>{item.name}</li>
    ))}
  </ul>
  {hasMoreOnRight && <ScrollFog side="right" />}
</div>
```

띠 폭은 `className`으로 바꿀 수 있습니다(예: `className="h-10"`).

## props

| prop   | 타입                                     | 기본값    | 설명                           |
| ------ | ---------------------------------------- | --------- | ------------------------------ |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"right"` | 붙을 가장자리                  |
| 나머지 | `ComponentPropsWithRef<"div">`           |           | `style`, `className`, `ref` 등 |

그라디언트 진행 방향은 `side`와 반대입니다. `side="right"`이면 왼쪽(투명)에서 오른쪽(`--umc-color-background-default`)으로 진행합니다.

## 접근성

`aria-hidden="true"`가 고정으로 달려 있어 스크린 리더에서 무시합니다.

## 디자인 팀 확인 사항

- 피그마에는 아래쪽 안개(높이 74px)만 있어서 위, 왼쪽, 오른쪽 안개는 같은 크기와 그라데이션을 돌려 썼습니다.
- 끝 색을 흰 배경(`background-default`)으로 가정했습니다. 회색 배경 위에서 쓸 안개가 필요한지 알려 주세요.
