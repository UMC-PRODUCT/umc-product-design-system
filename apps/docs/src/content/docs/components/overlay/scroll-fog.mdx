`ScrollFog`는 `position: absolute; inset: 0`으로 부모 요소를 기준으로 덮습니다. 부모에 `position: relative`가 필요합니다. `pointer-events: none`이어서 클릭과 스크롤을 막지 않습니다.

```tsx
import { ScrollFog } from "@umc-product/react"

;<div style={{ position: "relative", overflow: "hidden" }}>
  <ul style={{ overflowX: "auto" }}>
    {items.map((item) => (
      <li key={item.id}>{item.name}</li>
    ))}
  </ul>
  <ScrollFog side="right" style={{ width: "80px" }} />
</div>
```

## props

| prop   | 타입                                     | 기본값    | 설명                           |
| ------ | ---------------------------------------- | --------- | ------------------------------ |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"right"` | 그라디언트 방향                |
| 나머지 | `ComponentPropsWithRef<"div">`           |           | `style`, `className`, `ref` 등 |

그라디언트 진행 방향은 `side`와 반대입니다. `side="right"`이면 왼쪽(투명)에서 오른쪽(`--umc-color-background-default`)으로 진행합니다.

## 접근성

`aria-hidden="true"`가 고정으로 달려 있어 스크린 리더에서 무시합니다.
