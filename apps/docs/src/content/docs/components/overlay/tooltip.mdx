피그마 `Tooltip`을 옮겼습니다. 마우스를 올리면 열리는 방식은 Base UI Tooltip, 눌러서 여닫는 방식은 Base UI Popover로 만듭니다. 트리거는 자식 요소를 그대로 쓰므로 감싸는 `<span>`이 없고, 자식은 ref와 이벤트 핸들러를 받을 수 있어야 합니다.

```tsx
import { Tooltip } from "@umc-product/react"

<Tooltip content="저장 단축키: Ctrl+S">
  <button type="button">저장</button>
</Tooltip>
```

## 외형 미리보기

열린 툴팁의 모양을 항상 보이게 그린 미리보기입니다. 왼쪽부터 Xs Dark, Sm Dark, Sm Light, Md Dark, 라벨이 있는 Md Light입니다.

<TooltipStaticPreview />

## hover와 light 모드

기본값은 `openOn="hover"`, `mode="dark"`입니다.

<TooltipHover client:visible />

## 제목(label)

`title` prop을 넘기면 툴팁 상단에 초록 라벨이 생깁니다.

<TooltipWithTitle client:visible />

## 방향

`side`로 툴팁이 열릴 방향을 지정합니다. 공간이 부족하면 Base UI가 자동으로 반전합니다.

<TooltipSides client:visible />

## 클릭 트리거

`openOn="click"`으로 설정하면 외부 클릭 또는 Esc 키로 닫힙니다.

<TooltipClick client:visible />

## 크기

| size | 여백(상하, 좌우) | 모서리 | 글자                | 화살표 | 줄바꿈                      |
| ---- | ---------------- | ------ | ------------------- | ------ | --------------------------- |
| `xs` | 6px, 8px         | 6px    | `caption-2-regular` | 10×6px | 한 줄                       |
| `sm` | 6px, 8px         | 8px    | `body-3-medium`     | 10×6px | 한 줄                       |
| `md` | 8px, 12px        | 6px    | `caption-2-regular` | 16×8px | 최대 폭 240px 안에서 줄바꿈 |

## 모든 변형

피그마 `Tooltip` 변형 28개를 그렸습니다. 툴팁은 마우스를 올려야 뜨므로 화면에 고정해 그렸습니다. 칸에 마우스를 올리면 변형 이름이 보입니다.

<TooltipAllVariants />

## props

| prop       | 타입                                     | 기본값    | 설명             |
| ---------- | ---------------------------------------- | --------- | ---------------- |
| `content`  | `ReactNode`                              | 필수      | 툴팁 본문        |
| `title`    | `ReactNode`                              | 없음      | 초록 라벨        |
| `side`     | `"top" \| "bottom" \| "left" \| "right"` | `"top"`   | 열릴 방향        |
| `mode`     | `"dark" \| "light"`                      | `"dark"`  | 색 팔레트        |
| `size`     | `"xs" \| "sm" \| "md"`                   | `"md"`    | 크기             |
| `openOn`   | `"hover" \| "click"`                     | `"hover"` | 트리거 방식      |
| `delay`    | `number`                                 | 없음      | hover 딜레이(ms) |
| `children` | `ReactElement`                           | 필수      | 트리거 요소      |

## 알아 둘 점

- 툴팁의 최대 폭은 240px이고, 트리거와 8px 떨어져 뜹니다.
