피그마 `Web/Header`(node 2858:65987)를 구현했습니다. 로고, 가운데 내비게이션 알약, 오른쪽 액션 영역 세 칸으로 나뉩니다. 높이는 `--umc-layout-header-height`(80px)입니다. 양옆 칸은 내용보다 좁아지지 않고 남는 폭을 같은 비율로 나눠 가집니다. 양옆 내용 폭이 비슷하면 내비게이션이 가운데에 놓이고, 화면이 좁으면 내비게이션이 가로로 스크롤됩니다.

```tsx
import { Header, LinkProvider } from "@umc-product/react"
import Link from "next/link"
import { usePathname } from "next/navigation"

const navItems = [
  { label: "소개", href: "/about" },
  { label: "팀 매칭", href: "/matching" },
  { label: "지원하기", href: "/apply" },
]

export function AppHeader() {
  const pathname = usePathname()
  return (
    <LinkProvider component={Link}>
      <Header
        logo={<Logo />}
        navItems={navItems}
        currentPath={pathname}
        actions={<LoginButton />}
      />
    </LinkProvider>
  )
}
```

## 라이트 모드

관리자 화면과 일반 페이지의 기본 모드입니다. 항목을 누르면 선택 상태가 옮겨 갑니다.

<HeaderLight client:visible />

## 다크 모드

피그마 설명대로 주로 랜딩 페이지에서 씁니다. 헤더 배경은 투명하고, 뒤에 깔린 히어로 이미지나 배경이 그대로 보입니다. 내비게이션 알약은 반투명 배경에 `backdrop-filter: blur(21px)`를 씁니다.

<HeaderDark client:visible />

## 액션 버튼

`HeaderActionButton`은 피그마 `.primitive/Web/Header/Action Button`입니다. 로그인한 사용자에게 보이는 문의, 계정 메뉴 같은 보조 동작을 `actions`에 놓을 때 씁니다. 높이 40px 알약 모양이고, hover하면 테두리가 사라지고 배경이 짙어집니다. `suffix`에는 펼침 화살표 같은 16px 아이콘을 넣습니다.

```tsx
import { Header, HeaderActionButton } from "@umc-product/react"
import { ExpandMoreIcon } from "@umc-product/icons"

<Header
  logo={<Logo />}
  actions={
    <>
      <HeaderActionButton onClick={openInquiry}>문의사항</HeaderActionButton>
      <HeaderActionButton suffix={<ExpandMoreIcon />}>10기 운영진</HeaderActionButton>
    </>
  }
/>
```

<HeaderActions client:visible />

네이티브 `button` 속성을 받고 `type`의 기본값은 `"button"`입니다. 피그마의 `Profile`(원형 아바타)과 로고 hover는 에셋이 정해지지 않아 아직 컴포넌트로 만들지 않았습니다.

## 선택 상태

`currentPath`가 항목의 `href`와 같거나 그 하위 경로이면 `aria-current="page"`를 달고 선택 스타일을 적용합니다. 판정은 `isActivePath`가 맡습니다.

```ts
isActivePath("/matching/detail/1", "/matching") // true, 하위 경로
isActivePath("/matching", "/matching") // true, 완전 일치
isActivePath("/matching", "/m") // false, 경로 단위로만 비교
```

<Aside type="note">
  `href="/"`는 완전 일치만 선택합니다. `currentPath="/about"`일 때 루트 항목은
  선택되지 않습니다.
</Aside>

## props

| prop          | 타입                | 기본값    | 설명                                     |
| ------------- | ------------------- | --------- | ---------------------------------------- |
| `logo`        | `ReactNode`         | 없음      | 왼쪽 로고 영역                           |
| `navItems`    | `NavItem[]`         | 없음      | 가운데 내비게이션 항목. 비면 알약을 숨김 |
| `currentPath` | `string`            | 없음      | 현재 경로. 선택 항목 판정에 씀           |
| `actions`     | `ReactNode`         | 없음      | 오른쪽 액션 영역. 로그인 버튼, 프로필 등 |
| `mode`        | `"light" \| "dark"` | `"light"` | 색 모드                                  |
| `className`   | `string`            | 없음      | 루트 `header` 요소에 붙일 클래스         |

`NavItem`은 `{ label: ReactNode; href: string }`입니다.

## 고정 배치

`Header`는 위치를 정하지 않습니다. 스크롤해도 위에 남겨야 하면 레이아웃에서 지정합니다.

```tsx
<Header className="sticky top-0 z-50" logo={<Logo />} />
```

## 피그마와 다른 점

- 다크 모드 선택 항목: 피그마는 1px 테두리와 좌우 패딩 16px을 씁니다. 선택이 바뀔 때 폭이 흔들리지 않도록 패딩 18px을 유지하고 inset 그림자로 테두리를 그립니다.
- 내비게이션 알약 radius: 피그마 컨테이너는 9999px 리터럴, 항목은 999px 토큰입니다. 모양이 같으므로 `--umc-radius-full`로 통일했습니다.
