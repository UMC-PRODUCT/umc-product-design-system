`HeaderDesktop`, `SideNavigation`, `PageHeader`는 링크를 직접 만들지 않고 `LinkProvider`에 등록된 컴포넌트로 그립니다. 앱 루트에서 Next.js `Link`나 React Router `Link`를 한 번 등록하면 클라이언트 라우팅이 그대로 동작합니다. 등록하지 않으면 일반 `<a>`를 씁니다.

```tsx
import { LinkProvider } from "@umc-product/react"
import Link from "next/link"

export function Providers({ children }: { children: React.ReactNode }) {
  return <LinkProvider component={Link}>{children}</LinkProvider>
}
```

아래 예시는 기본 이동을 막고 받은 경로만 보여 주는 링크를 등록했습니다. 브레드크럼을 누르면 등록한 컴포넌트가 클릭을 받습니다.

## props

| prop        | 타입                                | 기본값 | 설명                           |
| ----------- | ----------------------------------- | ------ | ------------------------------ |
| `component` | `ComponentType<LinkComponentProps>` | 필수   | 셸 컴포넌트가 쓸 링크 컴포넌트 |
| `children`  | `ReactNode`                         | 필수   | 하위 트리                      |

등록하는 컴포넌트는 아래 props를 받아 그대로 렌더해야 합니다. Next.js `Link`와 React Router `Link`는 이 모양을 이미 받습니다. React Router는 `href` 대신 `to`를 쓰므로 감싸서 넘깁니다.

| prop           | 타입               | 설명                        |
| -------------- | ------------------ | --------------------------- |
| `href`         | `string`           | 이동할 경로                 |
| `className`    | `string`           | 셸 컴포넌트가 붙이는 클래스 |
| `children`     | `ReactNode`        | 링크 내용                   |
| `aria-current` | `"page" \| "step"` | 현재 위치 표시              |

```tsx
import { Link as RouterLink } from "react-router"
import type { LinkComponentProps } from "@umc-product/react"

function AppLink({ href, ...rest }: LinkComponentProps) {
  return <RouterLink to={href} {...rest} />
}
```
