셸 그룹의 `Header`, `SideNavigation`, `ContextSwitcher`, `PageHeader`를 조립하면 관리자 화면을 구성할 수 있습니다. 피그마 WorkFrame 프레임(node 2929:74971) 기준 레이아웃입니다.

<WorkFrameDemo />

## 레이아웃 구조

피그마 WorkFrame 치수:

| 영역                 | 너비                                | 높이 | 토큰                                  |
| -------------------- | ----------------------------------- | ---- | ------------------------------------- |
| Header               | 전체 너비                           | 80px | `--umc-layout-header-height: 5rem`    |
| SideNavigation       | 216px                               | 100% | `--umc-layout-sidebar-width: 13.5rem` |
| 콘텐츠 영역          | Header 아래 · SideNavigation 오른쪽 | —    | —                                     |
| PageHeader 위쪽 여백 | —                                   | 48px | —                                     |
| PageHeader 왼쪽 여백 | 32px                                | —    | —                                     |

```tsx
import {
  ContextSwitcher,
  Header,
  PageHeader,
  SideNavigation,
  LinkProvider,
} from "@umc-product/react"
import Link from "next/link"
import { usePathname } from "next/navigation"

export function AdminLayout({ children }: { children: React.ReactNode }) {
  const pathname = usePathname()

  return (
    <LinkProvider component={Link}>
      <div
        style={{ display: "flex", flexDirection: "column", minHeight: "100vh" }}
      >
        <Header
          logo={<Logo />}
          navItems={navItems}
          currentPath={pathname}
          className="sticky top-0 z-50"
        />
        <div style={{ display: "flex", flex: 1 }}>
          <SideNavigation
            items={sideItems}
            currentPath={pathname}
            slot={<GenerationSwitcher />}
          />
          <main style={{ flex: 1, padding: "48px 16px 16px 32px" }}>
            {children}
          </main>
        </div>
      </div>
    </LinkProvider>
  )
}
```

## sticky 헤더

`Header` 자체에는 `position: sticky`가 없습니다. 레이아웃에서 `className="sticky top-0 z-50"`을 추가합니다.

## ContextSwitcher 슬롯

`SideNavigation`의 `slot` prop에 `ContextSwitcher`를 전달합니다. 피그마 기준 너비는 172px입니다.
