피그마 `Web Frame`을 셸 컴포넌트로 조립한 예시입니다. 별도 컴포넌트가 아니라 레이아웃 패턴이라 앱에서 직접 짭니다. 메뉴를 누르면 헤더, 사이드 내비게이션, 페이지 헤더가 함께 바뀝니다.

## 헤더, 사이드 내비게이션, 브레드크럼 맞추기

HeaderDesktop, SideNavigation, PageHeader는 같은 메뉴 계층을 나눠서 보여 줍니다. 같은 번호가 붙은 자리는 같은 메뉴이므로 이름을 똑같이 씁니다.

<WorkFrameLevels client:visible />

| 번호                                                   | 단계        | HeaderDesktop         | SideNavigation             | PageHeader                    |
| ------------------------------------------------------ | ----------- | --------------------- | -------------------------- | ----------------------------- |
| <NumberBadge color="neutral" size="md">1</NumberBadge> | 서비스 영역 | 선택된 메뉴(리크루팅) | 이 영역의 메뉴를 모두 담음 | 브레드크럼 첫 항목            |
| <NumberBadge color="brand" size="md">2</NumberBadge>   | 메뉴 묶음   | 없음                  | 그룹(모집 관리)            | 브레드크럼 둘째 항목          |
| <NumberBadge color="warning" size="md">3</NumberBadge> | 현재 페이지 | 없음                  | 그룹 안 메뉴(모집 목록)    | 브레드크럼 마지막 항목과 제목 |

- 같은 번호는 글자를 똑같이 씁니다. 사이드 내비게이션에서 "모집 목록"이면 브레드크럼과 제목도 "모집 목록"이고, 줄이거나 다른 말로 바꾸지 않습니다.
- 그룹에 속하지 않은 메뉴는 2번을 건너뜁니다. 대시보드의 브레드크럼은 `리크루팅 › 대시보드`입니다.
- 브레드크럼의 앞 항목은 그 메뉴로 가는 링크입니다. 그룹(2번)에 따로 페이지가 없으면 링크 없이 둡니다. 마지막 항목은 현재 페이지라서 PageHeader가 링크 없이 `aria-current="page"`를 답니다.
- HeaderDesktop과 SideNavigation의 선택 표시는 같은 `currentPath`로 정합니다. 브레드크럼은 앱이 같은 메뉴 데이터에서 만들어 넘깁니다.

```tsx
import {
  HeaderDesktop,
  PageHeader,
  SideNavigation,
  type BreadcrumbItem,
  type NavItem,
  type SideNavigationItem,
} from "@umc-product/react"

const recruiting: NavItem = { label: "리크루팅", href: "/recruiting" }

const navItems: NavItem[] = [
  { label: "소개", href: "/about" },
  recruiting,
  { label: "설정", href: "/settings" },
]

const sideItems: SideNavigationItem[] = [
  { label: "대시보드", href: "/recruiting" },
  {
    label: "모집 관리",
    children: [
      { label: "모집 생성", href: "/recruiting/new" },
      { label: "모집 목록", href: "/recruiting/list" },
    ],
  },
]

function breadcrumbsOf(pathname: string): BreadcrumbItem[] {
  for (const item of sideItems) {
    if (!("children" in item)) {
      if (item.href === pathname) return [recruiting, { label: item.label }]
      continue
    }
    const page = item.children.find((child) => child.href === pathname)
    if (page) return [recruiting, { label: item.label }, { label: page.label }]
  }
  return []
}

export function RecruitingShell({ pathname }: { pathname: string }) {
  const breadcrumbs = breadcrumbsOf(pathname)
  return (
    <>
      <HeaderDesktop navItems={navItems} currentPath={pathname} />
      <SideNavigation items={sideItems} currentPath={pathname} />
      <PageHeader
        title={breadcrumbs.at(-1)?.label}
        breadcrumbs={breadcrumbs}
      />
    </>
  )
}
```

실제 배치는 아래 치수 절의 `AdminLayout`처럼 짭니다.

## 치수

| 영역                   | 값                            | 근거                                    |
| ---------------------- | ----------------------------- | --------------------------------------- |
| HeaderDesktop 높이     | 80px                          | `--umc-layout-header-height`            |
| SideNavigation 너비    | 216px                         | `--umc-layout-sidebar-width`            |
| 콘텐츠 영역 패딩       | 위 48px, 좌우 32px, 아래 80px | `--umc-spacing-margin-48`, `-32`, `-80` |
| PageHeader와 본문 사이 | 32px                          | `--umc-spacing-padding-32`              |

```tsx
import {
  HeaderDesktop,
  HeaderHomeLink,
  LinkProvider,
  PageHeader,
  SideNavigation,
} from "@umc-product/react"
import Link from "next/link"
import { usePathname } from "next/navigation"

export function AdminLayout({ children }: { children: React.ReactNode }) {
  const pathname = usePathname()
  return (
    <LinkProvider component={Link}>
      <div className="flex min-h-screen flex-col">
        <HeaderDesktop
          className="sticky top-0 z-50"
          logo={<HeaderHomeLink context="operation" generation={11} />}
          navItems={navItems}
          currentPath={pathname}
        />
        <div className="flex flex-1">
          <SideNavigation
            className="w-(--umc-layout-sidebar-width) shrink-0"
            items={sideItems}
            currentPath={pathname}
          />
          <main className="flex min-w-0 flex-1 flex-col gap-8 px-8 pt-12 pb-20">
            {children}
          </main>
        </div>
      </div>
    </LinkProvider>
  )
}
```

`HeaderDesktop`은 위치를 정하지 않으므로 고정이 필요하면 `className`으로 `sticky`를 줍니다. `SideNavigation`은 부모 폭을 채우므로 `w-(--umc-layout-sidebar-width) shrink-0`으로 사이드바 칸 폭을 정합니다. 높이는 `min-height: 100%`라서 부모 높이만큼 늘어납니다. 메뉴 위 `slot`은 서비스에 맞게 넣고 빼며, 넣을 수 있는 요소는 [SideNavigation 슬롯](../side-navigation/#슬롯)에 있습니다.
