피그마 `App/Bottom navigation`의 Android 변형을 구현했습니다. iOS 앱은 시스템이 제공하는 리퀴드 글래스 탭 바를 씁니다([Apple 탭 바 가이드](https://developer.apple.com/design/human-interface-guidelines/tab-bars)). 그래서 이 컴포넌트는 Android 앱과 웹 화면에서 씁니다.

iPhone 브라우저로 연 웹 화면에서는 `env(safe-area-inset-bottom)`으로 홈 인디케이터 영역을 비우고, 그 밖의 화면에서는 아래 여백을 최소 4px 둡니다. 현재 경로가 `href`와 같거나 그 하위 경로이면 그 탭에 `aria-current="page"`가 붙습니다.

```tsx
import {
  BottomNavigation,
  BottomNavigationItem,
  LinkProvider,
} from "@umc-product/react"
import { HomeIcon, SearchIcon } from "@umc-product/icons"
import Link from "next/link"
import { usePathname } from "next/navigation"

const NAV_ITEMS = [
  { label: "홈", href: "/", icon: <HomeIcon weight="fill" /> },
  { label: "검색", href: "/search", icon: <SearchIcon /> },
]

export function AppBottomNav() {
  const pathname = usePathname()
  return (
    <LinkProvider component={Link}>
      <BottomNavigation>
        {NAV_ITEMS.map((item) => (
          <BottomNavigationItem
            key={item.href}
            href={item.href}
            label={item.label}
            icon={item.icon}
            currentPath={pathname}
          />
        ))}
      </BottomNavigation>
    </LinkProvider>
  )
}
```

## props

### BottomNavigation

| prop        | 타입        | 기본값 | 설명                        |
| ----------- | ----------- | ------ | --------------------------- |
| `children`  | `ReactNode` | 필수   | `BottomNavigationItem` 목록 |
| `className` | `string`    | 없음   | 루트 엘리먼트 추가 클래스   |

### BottomNavigationItem

| prop          | 타입        | 기본값 | 설명                       |
| ------------- | ----------- | ------ | -------------------------- |
| `href`        | `string`    | 필수   | 탭 링크 경로               |
| `label`       | `string`    | 필수   | 탭 레이블 텍스트           |
| `icon`        | `ReactNode` | 필수   | 탭 아이콘 (24×24 SVG 권장) |
| `currentPath` | `string`    | 없음   | 활성 탭 판별용 현재 경로   |
| `className`   | `string`    | 없음   | 탭 엘리먼트 추가 클래스    |

`BottomNavigationItem`은 `<a>` 엘리먼트의 나머지 속성도 모두 받습니다. `aria-current`는 컴포넌트가 직접 관리하므로 외부에서 전달하면 타입 오류가 납니다.
