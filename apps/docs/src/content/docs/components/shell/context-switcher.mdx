피그마 `Context Switcher`(node 2281:6450)를 구현했습니다. 피그마 설명대로 워크스페이스, 계정 뷰, 관리 권한처럼 작업 맥락을 바꾸고 그에 따라 아래 메뉴가 달라지는 곳에 씁니다. 필요 없으면 쓰지 않습니다. 보통 `SideNavigation`의 `slot`에 넣습니다.

```tsx
import { ContextSwitcher, type ContextSwitcherOption } from "@umc-product/react"

type View = "challenger" | "chapter"

const views: ContextSwitcherOption<View>[] = [
  { value: "challenger", label: "챌린저 뷰" },
  { value: "chapter", label: "지부 운영진 뷰" },
]

export function ViewSwitcher() {
  const [view, setView] = useState<View>("chapter")
  return (
    <ContextSwitcher options={views} value={view} onValueChange={setView} />
  )
}
```

## 동작

- 버튼을 누르면 버튼 바로 아래에 목록이 열립니다. 목록 너비는 버튼과 같습니다.
- 선택된 항목은 연한 브랜드 배경과 체크 표시로 구분합니다. 키보드 방향키로 옮기고 Enter로 고릅니다.
- `value`와 `onValueChange`로만 제어합니다. 값 타입은 `options`의 `value`에서 추론합니다.

## props

| prop            | 타입                         | 설명                   |
| --------------- | ---------------------------- | ---------------------- |
| `options`       | `ContextSwitcherOption<V>[]` | 고를 수 있는 맥락 목록 |
| `value`         | `V`                          | 현재 맥락              |
| `onValueChange` | `(value: V) => void`         | 맥락을 고를 때 호출    |
| `className`     | `string`                     | 버튼에 붙일 클래스     |

`ContextSwitcherOption<V>`는 `{ value: V; label: ReactNode }`입니다.

## 피그마와 다른 점

- 너비: 피그마는 172px이지만 사이드 내비게이션 슬롯의 안쪽 폭은 168px입니다. `max-width: 100%`를 함께 걸어 슬롯 안에서는 168px로 줄어듭니다.
- 아이콘: 피그마는 16px 전용 아이콘(`icon/Expand_more/16`, `icon/Check/16`)을 씁니다. 아이콘 패키지에는 24px 아이콘만 있어 같은 아이콘을 16px로 줄여 씁니다. 선 굵기가 조금 다릅니다.
- 눌림 그림자와 선택 항목 그림자: 피그마 값(#D3D8D833, 1, 1, 2)이 이름 있는 스타일과 달라 컴포넌트 변수로 썼습니다.
