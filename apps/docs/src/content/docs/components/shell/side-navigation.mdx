피그마 `SideNavigation` 컴포넌트를 구현했습니다. 단일 링크와 펼침/접힘 그룹 두 가지 항목 유형을 지원합니다. 너비는 `--umc-layout-sidebar-width(13.5rem)`으로 고정됩니다.

```tsx
import { SideNavigation, type SideNavigationItem } from "@umc-product/react/shell"

const items: SideNavigationItem[] = [
  { label: "대시보드", href: "/dashboard" },
  {
    label: "매칭 관리",
    children: [
      { label: "매칭 목록", href: "/matching" },
      { label: "매칭 현황", href: "/matching/status" },
    ],
  },
]

export function AppSidebar() {
  return (
    <SideNavigation
      title="관리 메뉴"
      items={items}
      currentPath={pathname}
    />
  )
}
```

## 열림 초기값

`currentPath`가 주어지면 현재 경로를 포함하는 그룹을 자동으로 열어줍니다. 이후 열고 닫는 상태는 컴포넌트 내부에서 관리됩니다.

## props

| prop         | 타입                  | 기본값      | 설명                           |
| ------------ | --------------------- | ----------- | ------------------------------ |
| `items`      | `SideNavigationItem[]` | —          | 내비게이션 항목 목록           |
| `title`      | `string`              | `undefined` | 사이드바 제목 (섹션 헤더)      |
| `currentPath`| `string`              | `undefined` | 현재 경로                      |
| `slot`       | `ReactNode`           | `undefined` | 하단 추가 콘텐츠               |
| `aria-label` | `string`              | `undefined` | nav 요소 접근성 레이블         |
| `className`  | `string`              | `undefined` | 루트 요소 추가 클래스          |

### SideNavigationItem

```ts
type SideNavigationItem =
  | SideNavigationLeaf                       // 단일 링크
  | { label: string; children: SideNavigationLeaf[] } // 그룹
```

### SideNavigationLeaf

| 필드    | 타입     | 설명        |
| ------- | -------- | ----------- |
| `label` | `string` | 메뉴 레이블 |
| `href`  | `string` | 이동 경로   |

## 디자인 팀 확인 사항

- 오른쪽 경계선 색 `#e9ecec`가 토큰에 없어 컴포넌트 변수로 선언했습니다. `--umc-color-teal-grey-200(#e2e3e3)`과 다른 값입니다.
