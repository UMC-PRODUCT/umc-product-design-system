피그마 `Web/Side Navigation`(node 2929:72851)을 구현했습니다. 너비는 `--umc-layout-sidebar-width`(216px)입니다. 항목은 링크 하나로 끝나는 메뉴와 하위 메뉴를 펼치는 그룹 두 종류입니다.

```tsx
import { SideNavigation, type SideNavigationItem } from "@umc-product/react"
import { PeoplePictogram } from "@umc-product/icons"

const items: SideNavigationItem[] = [
  {
    label: "대시보드",
    href: "/manage",
    icon: <PeoplePictogram color="currentColor" />,
  },
  {
    label: "매칭 관리",
    icon: <PeoplePictogram color="currentColor" />,
    children: [
      { label: "매칭 목록", href: "/manage/matching" },
      { label: "매칭 현황", href: "/manage/matching/status" },
    ],
  },
]

export function AdminSidebar({ pathname }: { pathname: string }) {
  return (
    <SideNavigation title="관리 메뉴" items={items} currentPath={pathname} />
  )
}
```

## 기본

메뉴를 누르면 선택이 옮겨 가고, 그룹을 누르면 하위 메뉴를 펼치거나 접습니다. 여러 그룹을 동시에 펼칠 수 있습니다.

<SideNavigationDefault client:visible />

## 슬롯

`slot`은 메뉴 위에 놓입니다. 피그마 예시처럼 `ContextSwitcher`나 검색 필드를 넣습니다. 슬롯 영역의 좌우 패딩은 32px, 16px입니다.

<SideNavigationWithSlot client:visible />

## 선택과 펼침

- `currentPath`와 맞는 `href` 가운데 가장 구체적인 항목 하나만 선택합니다. `/matching`과 `/matching/status`가 함께 있으면 `/matching/status/3`에서는 `/matching/status`만 선택됩니다.
- 선택된 하위 메뉴를 담은 그룹은 그룹 버튼에도 선택 스타일을 적용합니다.
- 처음 렌더할 때, 그리고 `currentPath`가 다른 그룹 안으로 바뀔 때 그 그룹을 펼칩니다. 이미 펼쳐 둔 다른 그룹은 닫지 않습니다.

## 아이콘

아이콘 칸은 20px이고 색은 상태를 따라 바뀝니다(기본 `--umc-color-icon-neutral-weak-400`, 선택 `--umc-color-icon-brand-strong-600`). 일반 아이콘은 `currentColor`를 쓰므로 그대로 넣습니다. 픽토그램은 자기 색을 갖고 있어 `color="currentColor"`를 넘겨야 상태 색을 따릅니다.

## 모든 변형

피그마 `Web/Side Navigation` 2개, `Menu Item` 6개, `Submenu Item` 2개를 그렸습니다. 선택된 메뉴 항목은 피그마처럼 하위 메뉴를 펼친 모습입니다. 칸에 마우스를 올리면 피그마 변형 이름이 보입니다. Hover처럼 마우스가 있어야 보이는 상태는 문서에서 켜 둔 모습입니다.

## props

| prop          | 타입                   | 기본값                | 설명                                   |
| ------------- | ---------------------- | --------------------- | -------------------------------------- |
| `items`       | `SideNavigationItem[]` | 없음                  | 메뉴 목록                              |
| `currentPath` | `string`               | 없음                  | 현재 경로. 선택과 펼침 판정에 씀       |
| `title`       | `ReactNode`            | 없음                  | 메뉴 위 제목. 있으면 `nav`의 이름이 됨 |
| `slot`        | `ReactNode`            | 없음                  | 메뉴 위에 놓을 요소                    |
| `aria-label`  | `string`               | `"사이드 내비게이션"` | `title`이 없을 때 `nav`의 이름         |
| `className`   | `string`               | 없음                  | 루트 `nav` 요소에 붙일 클래스          |

```ts
type SideNavigationLeaf = { label: ReactNode; href: string }
type SideNavigationLink = SideNavigationLeaf & { icon?: ReactNode }
type SideNavigationGroup = {
  label: ReactNode
  icon?: ReactNode
  children: SideNavigationLeaf[]
}
type SideNavigationItem = SideNavigationLink | SideNavigationGroup
```

`href`와 `children`이 둘 다 없는 항목은 타입 단계에서 막습니다.

## 피그마와 다른 점

- 그룹 동작: 피그마 설명은 "선택 시 최상단 서브 메뉴도 함께 Active되며 그 페이지가 열림"입니다. 이 컴포넌트의 그룹 버튼은 펼침과 접힘만 맡고 이동하지 않습니다. 한 버튼이 이동과 접기를 함께 하면 접으려고 누를 때도 페이지가 바뀌기 때문입니다. 그룹을 열 때 첫 하위 페이지로 보내려면 앱 라우팅에서 처리합니다.
- 오른쪽 경계선: `Type=Default`는 2기 변수 `teal-gray-200`(#e9ecec), `Type=With Slot`은 `Border/Neutral/Weak-200`(#e2e3e3)을 씁니다. 3기 토큰 `--umc-color-border-neutral-weak-200`로 통일했습니다.
- hover 그림자: 피그마 스타일 이름은 `Shadow/Inner/Neutral_1`이지만 값이 파운데이션 정의와 다릅니다(#D3D8D833, 1, 1, 2). 이름 있는 스타일은 토큰을 따르는 규칙대로 `--umc-shadow-inner-neutral-1`을 씁니다.
- 긴 메뉴 이름은 한 줄을 넘으면 말줄임표로 자릅니다. 피그마에는 넘치는 경우가 없습니다.
