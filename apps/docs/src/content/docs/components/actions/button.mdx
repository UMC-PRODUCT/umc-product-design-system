피그마 `Button`(노드 2621:33584)의 색 4종, 스타일 2종, 크기 4종, 상태 4종을 하나의 컴포넌트로 옮겼습니다. 렌더되는 요소는 항상 `<button>`이고, 네이티브 `button` 속성을 모두 타입 검사와 함께 받습니다.

```tsx
import { Button } from "@umc-product/react"

<Button
  variant="fill"
  color="primary"
  size="md"
  isLoading={isPending}
  onClick={save}
>
  저장
</Button>
```

## 색과 스타일

마우스를 올리거나 누르면 피그마의 Pressed 모양이 됩니다. 로딩 모양은 비활성보다 우선합니다.

## 아이콘

`leadingIcon`, `trailingIcon`에 아이콘을 넘기면 크기(md, lg 16px, sm, xs 14px)와 아이콘 쪽 여백을 버튼이 맞춥니다. 아이콘 색은 글자색을 따르고, 화면 낭독기에서는 숨깁니다.

<ButtonIcons />

## 로딩

라벨을 투명하게 남겨 두므로 로딩이 시작되어도 버튼 폭이 그대로입니다. 포커스를 잃지 않도록 `disabled` 대신 `aria-disabled`, `aria-busy`를 달고 클릭과 form 제출을 막습니다. 화면 낭독기는 "지원서 제출하기 로딩 중"으로 읽습니다.

<ButtonLoadingWidth />

## className으로 덮어쓰기

버튼 CSS는 `@layer components`에 있어서 앱의 Tailwind 유틸리티가 항상 이깁니다. 병합 함수 없이 `className`을 그대로 붙이면 됩니다.

<ButtonOverride />

<Aside type="caution">
  `bg-*`로 배경을 바꾸면 눌림과 비활성 상태까지 그 색으로 덮입니다. 색은
  `color`, `variant`로 고르는 것을 기본으로 합니다.
</Aside>

## props

| prop                          | 타입                                         | 기본값          | 설명                                     |
| ----------------------------- | -------------------------------------------- | --------------- | ---------------------------------------- |
| `variant`                     | `"fill" \| "weak"`                           | `"fill"`        | 피그마 Style                             |
| `color`                       | `"primary" \| "neutral" \| "red" \| "white"` | `"primary"`     | 피그마 Color                             |
| `size`                        | `"lg" \| "md" \| "sm" \| "xs"`               | `"md"`          | 피그마 Size                              |
| `isLoading`                   | `boolean`                                    | `false`         | 피그마 State=Loading                     |
| `leadingIcon`, `trailingIcon` | `ReactNode`                                  | 없음            | 피그마 Icon Position                     |
| 나머지                        | `ComponentPropsWithRef<"button">`            | `type="button"` | `ref`, `aria-*`, `data-*`, 이벤트 핸들러 |

## 디자인 팀 확인 사항

- Hover 상태가 없어서 마우스가 있는 기기에서는 Pressed 모양을 함께 씁니다.
- Focus 상태가 없어서 2px `border-primary-strong` 외곽선을 넣었습니다.
- 아이콘 변형의 색(Primary Fill `#02746c`, Md Neutral Fill `#7e7f7f`)이 아이콘 없는 변형과 달라 아이콘 없는 변형으로 통일했습니다.
- Neutral Fill Default 배경이 Disabled 배경과 같습니다(`#adadad`).
- Sm 크기 글자의 자간이 피그마 컴포넌트에서는 -3%입니다. 예전에 게시된 `Label/3-Medium`을 참조해서 생긴 차이로 보고 토큰 값(-2%)을 썼습니다.
- Lg 크기에는 아이콘 변형이 없어 Md와 같은 16px, 아이콘 쪽 여백 14px로 가정했습니다.
