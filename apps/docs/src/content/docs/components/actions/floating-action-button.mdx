피그마 `Floating Action Button`을 옮겼습니다. 54px 원 안에 30px 아이콘 하나만 두고, 마우스를 올리면 배경과 테두리, 아이콘이 브랜드색으로 바뀝니다. 질문지 편집 화면에서는 [FormQuestionToolbar](../../questionnaire/form-question-toolbar/)가 이 버튼으로 질문 유형 목록을 엽니다. 렌더되는 요소는 `<button>`이고 네이티브 `button` 속성을 모두 받습니다.

```tsx
import { AddIcon } from "@umc-product/icons"
import { FloatingActionButton } from "@umc-product/react"

<FloatingActionButton
  icon={<AddIcon weight="fill" />}
  aria-label="질문 추가"
  onClick={openQuestionTypes}
/>
```

## 접근 가능한 이름

글자가 없는 버튼이라 `aria-label`이 타입에서 필수입니다. 빠뜨리면 컴파일되지 않습니다. 아이콘은 `aria-hidden`으로 숨겨 이름만 읽힙니다. 버튼이 목록을 열고 닫는다면 `aria-expanded`와 `aria-controls`를 함께 넘겨 주세요.

## 위치

버튼은 놓인 자리에 그려지고 화면에 고정되지 않습니다. 화면 아래에 띄워 두려면 감싼 요소나 `className`으로 `position: fixed`를 줍니다.

## props

| prop         | 타입                              | 기본값 | 설명                                                 |
| ------------ | --------------------------------- | ------ | ---------------------------------------------------- |
| `icon`       | `ReactNode`                       | 필수   | 가운데 아이콘. 30px로 맞춤                           |
| `aria-label` | `string`                          | 필수   | 버튼 이름                                            |
| 나머지       | `ComponentPropsWithRef<"button">` | 없음   | `type`의 기본값은 `"button"`. `children`은 받지 않음 |

## 알아 둘 점

- 그림자는 3기 토큰 `shadow-drop-neutral-2`를 씁니다. 피그마 스타일의 색(#EFF0F080)과 토큰의 색(#eceeee85)이 조금 다릅니다.
- 피그마에 비활성 변형이 없습니다. `disabled`이면 아이콘만 비활성 색으로 바뀝니다.
