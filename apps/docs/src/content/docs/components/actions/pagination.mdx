목록 아래에서 페이지를 옮기는 번호 묶음입니다. 전체 페이지 수(`totalPages`)를 넘기면 번호와 화살표를 그리고, 번호나 화살표를 누르면 `onPageChange`로 옮겨 갈 페이지를 알려 줍니다.

```tsx
import { Pagination } from "@umc-product/react"

<Pagination totalPages={12} defaultPage={1} onPageChange={loadPage} />
```

## 첫 페이지와 마지막 페이지

넘어갈 페이지가 없으면 그쪽 화살표를 지웁니다. 첫 페이지에는 이전 화살표가, 마지막 페이지에는 다음 화살표가 없습니다. 화살표는 한 페이지씩 옮깁니다.

<PaginationPositions />

## 페이지가 많을 때

번호는 `visibleCount`(기본 4)개씩 묶어 보여 줍니다. 4페이지에서 다음 화살표를 누르면 5페이지로 가면서 번호가 5~8로 바뀝니다. 페이지가 하나면 번호 하나만 그리고, 0이면 아무것도 그리지 않습니다.

<PaginationGroups client:visible />

## 제어형으로 쓰기

주소의 쿼리처럼 페이지를 바깥에서 들고 있으면 `page`와 `onPageChange`를 함께 넘깁니다. 범위를 벗어난 `page`는 가까운 끝 페이지로 맞춰 그립니다.

```tsx
const [page, setPage] = useState(1)

<Pagination totalPages={totalPages} page={page} onPageChange={setPage} />
```

## 접근성

- `nav`로 감싸고 이름을 "페이지 이동"으로 붙입니다. 한 화면에 여러 개를 두면 `aria-label`로 구분합니다.
- 현재 번호에 `aria-current="page"`를 답니다. 번호는 "3페이지", 화살표는 "이전 페이지"와 "다음 페이지"로 읽고, `pageLabel`, `previousLabel`, `nextLabel`로 바꿀 수 있습니다.
- 화살표로 끝 페이지에 닿아 화살표가 사라지면 포커스를 현재 번호로 옮겨 키보드 위치를 잃지 않게 합니다.

## props

| prop                         | 타입                           | 기본값                           | 설명                                   |
| ---------------------------- | ------------------------------ | -------------------------------- | -------------------------------------- |
| `totalPages`                 | `number`                       | 필수                             | 전체 페이지 수                         |
| `page`                       | `number`                       | 없음                             | 현재 페이지(제어형)                    |
| `defaultPage`                | `number`                       | `1`                              | 처음 페이지(비제어형)                  |
| `onPageChange`               | `(page: number) => void`       | 없음                             | 옮겨 갈 페이지를 받는 함수             |
| `visibleCount`               | `number`                       | `4`                              | 한 번에 보이는 번호 수                 |
| `previousLabel`, `nextLabel` | `string`                       | `"이전 페이지"`, `"다음 페이지"` | 화살표 이름                            |
| `pageLabel`                  | `(page: number) => string`     | `` (page) => `${page}페이지` ``  | 번호 이름                              |
| 나머지                       | `ComponentPropsWithRef<"nav">` | `aria-label="페이지 이동"`       | `ref`, `className`, `aria-*`, `data-*` |
