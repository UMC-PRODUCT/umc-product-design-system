디자인 시스템은 패키지 세 개로 나뉩니다.

| 패키지                       | 내용                                                   | 의존                   |
| ---------------------------- | ------------------------------------------------------ | ---------------------- |
| `@umc-product/design-tokens` | 피그마 토큰을 CSS 변수, Tailwind v4, vanilla-extract로 | 없음                   |
| `@umc-product/icons`         | 아이콘 64종, 픽토그램 10종, 로고 React 컴포넌트        | React 19               |
| `@umc-product/react`         | Base UI 위에 만든 컴포넌트와 미리 빌드한 CSS           | React 19, 위 두 패키지 |

모든 산출물은 같은 `--umc-*` CSS 변수를 가리키기 때문에, 앱이 어떤 스타일 도구를 쓰든 같은 값이 나옵니다.

## 토큰 산출물

| 경로                                         | 내용                                                                                    | 쓰는 곳              |
| -------------------------------------------- | --------------------------------------------------------------------------------------- | -------------------- |
| `@umc-product/design-tokens/base.css`        | 모든 토큰의 `--umc-*` CSS 변수                                                          | 모든 앱              |
| `@umc-product/design-tokens/fonts.css`       | Pretendard Variable 웹폰트                                                              | 모든 앱              |
| `@umc-product/design-tokens/tailwind.css`    | Tailwind v4 컬러, 텍스트 스타일, 그림자, 그리드와 레이아웃 유틸리티, 기본 팔레트 초기화 | Tailwind 앱          |
| `@umc-product/design-tokens/vanilla-extract` | `vars`, `typography` 객체                                                               | vanilla-extract 앱   |
| `@umc-product/design-tokens`                 | `textStyleUtilities`, `shadowUtilities`, `cssVariables`                                 | tailwind-merge, 도구 |
| `@umc-product/design-tokens/manifest`        | 토큰별 최종 값, 참조, 피그마 이름, 추천 클래스                                          | 문서, 도구           |

## CSS 불러오기

컴포넌트를 쓰는 앱은 `@umc-product/react/styles.css` 하나를 불러옵니다. 이 파일이 `fonts.css`, `base.css`, 헤더 홈 링크의 Orbitron 글꼴을 함께 불러오므로 토큰 CSS를 따로 넣지 않아도 됩니다. Tailwind 유틸리티로 토큰을 쓰려면 `tailwind.css`를 더합니다.

```css
@import "tailwindcss";
@import "@umc-product/react/styles.css";
@import "@umc-product/design-tokens/tailwind.css";
```

토큰만 쓰는 앱은 아래처럼 불러옵니다. 순서가 중요합니다.

```css
@import "tailwindcss";
@import "@umc-product/design-tokens/fonts.css";
@import "@umc-product/design-tokens/base.css";
@import "@umc-product/design-tokens/tailwind.css";
```

`base.css`를 빠뜨리면 유틸리티가 빈 변수를 참조해, 오류 없이 스타일만 사라집니다. vanilla-extract만 쓰는 앱은 `tailwind.css`를 빼고 나머지 파일만 전역에서 한 번 불러옵니다.

## 컴포넌트와 아이콘 쓰기

```tsx
import { Button, TextField } from "@umc-product/react"
import { SearchIcon } from "@umc-product/icons"

<TextField label="이름" placeholder="이름을 입력하세요" />
<Button size="md" leadingIcon={<SearchIcon />}>
  검색
</Button>
```

- **스타일 덮어쓰기**: 컴포넌트 스타일은 `@layer components`에 있습니다. Tailwind 유틸리티(`utilities` 레이어)와 레이어 밖에 선언되는 vanilla-extract 스타일이 모두 컴포넌트보다 우선하므로 `className`으로 덮어쓸 수 있습니다. `styles.css`를 Tailwind보다 먼저 불러와도 레이어 순서는 같습니다.
- **서버 컴포넌트**: 상호작용이 있는 컴포넌트는 `"use client"`를 선언해 두었습니다. Next.js App Router의 서버 컴포넌트 안에 그대로 놓을 수 있습니다.
- **라우터 링크**: `Header`, `SideNavigation`, `PageHeader`가 그리는 링크는 [LinkProvider](/components/shell/link-provider/)로 앱의 라우터 링크를 등록해 바꿉니다.
- **아이콘 색**: 아이콘은 `currentColor`를 쓰므로 글자색을 따릅니다. 픽토그램은 자기 색을 갖고 있어서 상태 색을 따르게 하려면 `color="currentColor"`를 넘깁니다.

## 주의할 점

- **Tailwind 기본 팔레트를 지웁니다.** `tailwind.css`가 기본 색을 지우고 피그마 색만 등록하므로 `bg-teal-500`은 피그마 `Teal-500`입니다. 앱에만 필요한 색은 `tailwind.css`를 불러온 뒤의 `@theme`에 더합니다. `tailwind.css`를 `@import "tailwindcss"`보다 먼저 불러오면 기본 팔레트가 되살아납니다.
- **토큰 덮어쓰기는 레이어 밖에서 합니다.** 토큰은 `@layer umc.tokens`에 선언되어 있어서 `@layer base` 안에서 `--umc-*`를 바꾸면 적용되지 않습니다.
- **브레이크포인트 토큰은 아직 없습니다.** 디자인 팀과 경계값을 정할 때까지 앱의 기존 브레이크포인트를 씁니다.
