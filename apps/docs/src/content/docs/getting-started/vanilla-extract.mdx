---
title: vanilla-extract에서 쓰기
description: vanilla-extract 앱에서 토큰 객체를 쓰는 방법입니다.
---

`@umc-product/design-tokens/vanilla-extract`는 `var(--umc-…)` 문자열만 담은 객체입니다. 그래서 패키지는 vanilla-extract에 의존하지 않고, 앱은 `fonts.css`와 `base.css`를 전역에서 한 번 불러온 뒤 객체를 `style()`에 넘깁니다.

## 객체 구조

| 객체          | 내용                   | 예                               |
| ------------- | ---------------------- | -------------------------------- |
| `vars.color`  | semantic 컬러 151개    | `vars.color.text.neutralDefault` |
| `vars.grid`   | 컬럼 수, 거터, 마진    | `vars.grid.margin.desktop`       |
| `vars.layout` | 헤더 높이, 사이드바 폭 | `vars.layout.header.height`      |
| `typography`  | 텍스트 스타일 48개     | `typography.body1Regular`        |

토큰 이름의 하이픈 구간은 camelCase 키가 됩니다. 예를 들어 `color.fill.primary.weaker-hover-pressed`는 `vars.color.fill.primary.weakerHoverPressed`입니다.

## 예시

```ts
import { style } from "@vanilla-extract/css"
import { typography, vars } from "@umc-product/design-tokens/vanilla-extract"

export const title = style({
  ...typography.display1Bold,
  color: vars.color.text.neutralDefault,
})

export const content = style({
  display: "grid",
  gridTemplateColumns: `repeat(${vars.grid.columns}, minmax(0, 1fr))`,
  columnGap: vars.grid.gutter,
  paddingInline: vars.grid.margin.desktop,
})
```

간격과 모서리처럼 `vars`에 없는 토큰은 CSS 변수 문자열로 씁니다(예: `borderRadius: "var(--umc-radius-button-12)"`).
