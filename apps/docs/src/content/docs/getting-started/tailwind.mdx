`tailwind.css`를 불러오면 semantic 컬러, 텍스트 스타일, 그리드와 레이아웃 유틸리티가 생깁니다. primitive 컬러는 유틸리티를 만들지 않으니 앱에서는 semantic 이름만 씁니다.

## 유틸리티 이름

| 종류             | 형식                                           | 예                                                                     |
| ---------------- | ---------------------------------------------- | ---------------------------------------------------------------------- |
| 텍스트 색        | `text-fg-…`                                    | `text-fg-neutral-default`, `text-fg-brand-default`                     |
| 배경과 면        | `bg-background-…`, `bg-surface-…`, `bg-fill-…` | `bg-surface-default`, `bg-fill-primary-strong`                         |
| 테두리           | `border-border-…`                              | `border-border-neutral-weak`                                           |
| 아이콘           | `text-icon-…`                                  | `text-icon-neutral-strong`                                             |
| 태그             | `bg-tag-…`, `text-tag-…`                       | `bg-tag-part-pm-weaker`, `text-tag-part-pm-strong`                     |
| 텍스트 스타일    | `text-<스타일>`                                | `text-body-1-regular`                                                  |
| 그리드, 레이아웃 | 간격과 크기 유틸리티                           | `gap-x-grid-gutter`, `px-grid-margin-desktop`, `h-header`, `w-sidebar` |

Text 그룹만 `text-text-…`가 되지 않도록 `fg`로 바꿨습니다. 전체 이름은 [컬러](/foundations/color/) 페이지에 있습니다.

## 예시

<div class="not-content umc-canvas rounded-xl border border-border-neutral-weak p-6">
  <p class="text-label-5-semibold text-fg-brand-default">UMC 11기</p>
  <p class="text-heading-2-bold text-fg-neutral-default mt-1">챌린저 모집</p>
  <p class="text-body-2-regular text-fg-neutral-medium mt-2">
    세상의 틀을 깰 챌린저들이 하나로 모이는 곳
  </p>
  <span class="text-label-6-semibold mt-4 inline-block rounded-full bg-tag-part-pm-weaker px-3 py-1 text-tag-part-pm-strong">
    PM
  </span>
</div>

```html

  </span>

```

## 간격과 모서리

간격과 모서리 토큰은 유틸리티를 만들지 않았습니다. Tailwind v4의 CSS 변수 문법으로 씁니다.

```html
<div class="p-(--umc-spacing-padding-16) rounded-(--umc-radius-button-12)">
  …
</div>
```

## tailwind-merge 등록

텍스트 스타일 유틸리티는 Tailwind 기본 이름이 아니라서, 등록하지 않으면 `cn()`이 색상 클래스로 오인해 지울 수 있습니다.

```ts
import { textStyleUtilities } from "@umc-product/design-tokens"
import { extendTailwindMerge } from "tailwind-merge"

export const twMerge = extendTailwindMerge({
  extend: {
    classGroups: {
      "font-size": [...textStyleUtilities],
    },
  },
})
```

<Aside type="caution">
  Tailwind v4에는 tailwind-merge v3 이상이 필요합니다. v2는 Tailwind v3용이라
  유틸리티를 잘못 분류할 수 있습니다.
</Aside>
