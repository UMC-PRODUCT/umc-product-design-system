`@umc-product/icons`는 피그마 아이콘 페이지에서 받은 SVG를 React 컴포넌트로 만든 패키지입니다. 아이콘마다 모듈이 따로 있어서 불러온 아이콘만 번들에 들어갑니다.

```tsx
import { AddIcon, CloseIcon } from "@umc-product/icons"

<AddIcon />
<AddIcon weight="fill" size={20} className="text-brand-default-600" />
<button type="button" aria-label="닫기">
  <CloseIcon />
</button>
```

## 아이콘 찾기

컴포넌트 이름이나 피그마 이름으로 찾습니다. 카드를 누르면 불러오는 코드가 위에 나타납니다.

## 굵기와 크기

| prop     | 타입                             | 기본값              | 설명                                             |
| -------- | -------------------------------- | ------------------- | ------------------------------------------------ |
| `weight` | 아이콘에 있는 굵기만             | regular, fill, thin | 피그마 Weight. 앞의 순서로 처음 있는 굵기가 기본 |
| `size`   | `number \| string`               | `24`                | 너비와 높이를 같이 바꿈                          |
| 나머지   | `SVGProps<SVGSVGElement>`, `ref` | 없음                | `className`, `style`, `aria-*`를 그대로 전달     |

`weight`는 아이콘마다 피그마에 있는 굵기만 받습니다. `BoldIcon`처럼 Fill만 있는 아이콘에 `weight="thin"`을 넘기면 타입 오류가 납니다.

## 작은 크기

16px 아이콘 세트는 따로 없습니다. 피그마 컴포넌트도 16px, 14px 자리에 24px 아이콘을 줄여 넣었으므로 `size`만 바꿉니다. 작게 줄이면 선이 얇아 보여서 피그마는 대부분 Fill을 골랐습니다. 같은 모양을 내려면 아래 굵기를 따릅니다.

| 쓰는 곳                         | 아이콘                       | 크기                | 굵기    |
| ------------------------------- | ---------------------------- | ------------------- | ------- |
| Button 앞뒤 아이콘              | `AddIcon`                    | md 16px, sm·xs 14px | fill    |
| Select 화살표, Header 액션 버튼 | `ExpandMoreIcon`             | 16px                | fill    |
| Numeric Stepper 증감 버튼       | `AddIcon`, `SubtractionIcon` | 16px                | fill    |
| Text Info Button                | `InfoIcon`                   | 16px                | regular |
| Search Field 드롭다운 검색창    | `SearchIcon`                 | 16px                | regular |

Dropdown과 Context Switcher의 체크, Context Switcher 화살표, Toast 닫기, Option Button 체크는 라이브러리 아이콘이 아닙니다. 컴포넌트 안에만 있는 그림이라 컴포넌트가 피그마 그림을 그대로 그리고, 패키지로 내보내지 않습니다. 라이브러리 아이콘으로 바꿀지는 [디자인 팀 확인 목록](../../contributing/design-questions/)에 올렸습니다.

## 색

아이콘의 주색(피그마 `#3f4141`)은 `currentColor`로 바꿨습니다. 그래서 아이콘은 감싼 요소의 글자색을 따르고, `className="text-brand-default-600"`나 `style={{ color }}`로 색을 바꿉니다. Notification의 빨간 점과 몇몇 아이콘의 흰 부분은 의미가 있는 색이라 토큰(`red-500`, `white`)으로 고정했습니다.

## 접근성

아이콘은 기본으로 `aria-hidden="true"`인 장식 요소입니다. 아이콘만 있는 버튼에는 버튼 쪽에 `aria-label`을 붙입니다. 아이콘 자체가 뜻을 전해야 하면 아이콘에 `aria-label`을 주세요. 그러면 `role="img"`로 바뀌어 화면 낭독기가 읽습니다.

## 픽토그램

픽토그램은 기본 크기가 30px입니다. 주색은 `color`를 따르고, 기본값은 변형마다 피그마에 칠해진 색입니다. `mode`가 있는 픽토그램은 `mode="dark"`로 어두운 변형을 고릅니다.

```tsx
import { SchoolPictogram, UnderConstructionPictogram } from "@umc-product/icons"

<SchoolPictogram />
<UnderConstructionPictogram mode="dark" size={48} />
```

## 로고

`Logo/UMC`(node 2678:52296)는 `UmcLogo`입니다. 아이콘과 달리 가로로 긴 그림이라 `size` 대신 `height`를 받고, 너비는 피그마 비율(148:44)로 정합니다. 기본 높이는 헤더 홈 링크와 같은 22px입니다. 주색은 아이콘처럼 `currentColor`를 따릅니다.

```tsx
import { UmcLogo } from "@umc-product/icons"

<UmcLogo />
<UmcLogo height={44} aria-label="UMC" />
```

<LogoGallery />

헤더에 로고를 놓을 때는 `UmcLogo`를 직접 쓰지 말고 [Header](../../components/shell/header/)의 `HeaderHomeLink`를 씁니다. 링크, 맥락 이름, hover 색까지 피그마 `Web/Header/Home Link`대로 맞춰 둔 컴포넌트입니다.

## 피그마와 다른 점

- Chevron, Person, Setting, Under-construction은 피그마가 프레임 대신 안쪽 도형만 내보내서 원래 위치로 옮겼습니다.
- 23.85×25처럼 정사각형이 아닌 프레임은 viewBox를 피그마 값 그대로 두고, 정사각형 안에 비율을 지켜 넣었습니다.
- `Pictogram/Person`은 SVG가 아니라 PNG 마스크라서 패키지에서 뺐습니다.
- 피그마에서 선이 살아 있는 아이콘(예: `Icon/Check`)은 인스턴스를 줄여도 선 두께가 그대로입니다. 패키지 아이콘은 크기에 비례해 선도 같이 얇아집니다.

## 아이콘을 추가하거나 바꿀 때

1. 피그마 노드의 SVG를 `packages/icons/figma/svg/<노드 id>.svg`로 저장하고, `figma/manifest.json`에 노드 id와 sha256을 적습니다.
2. `pnpm icons:build`를 실행합니다. 이름, 굵기, 캔버스, 색 규칙에 맞지 않으면 노드 이름과 함께 실패합니다.
3. 실패 메시지를 보고 `scripts/rules.ts`에 규칙을 더합니다. 규칙에는 피그마와 다르게 옮긴 이유를 적습니다.
4. `pnpm icons:check`와 `pnpm test`로 생성물과 원문이 맞는지 확인합니다.
