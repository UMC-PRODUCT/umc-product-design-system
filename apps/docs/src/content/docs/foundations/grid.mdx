그리드는 값과 배치 규칙으로 나눠 옮겼습니다. 컬럼 수, 마진, 거터, 헤더와 사이드바 크기는 토큰으로 두고, 배치는 CSS Grid로 합니다.

## 데스크톱 규칙

- 기본 프레임은 1440 × 900이고, 헤더 80px가 화면 전체 폭을 차지합니다
- 사이드바는 216px로 고정이고, 콘텐츠 영역이 나머지 폭을 채웁니다
- 콘텐츠 영역은 12컬럼입니다. 마진 32px와 거터 16px는 고정이고, 컬럼은 남은 폭을 나눠 가집니다(Stretch)
- 컬럼 폭 82px는 1440 화면에서 나오는 결과값이라 토큰으로 두지 않았습니다

아래 슬라이더로 프레임 폭을 바꿔 보면 마진과 거터는 그대로이고 컬럼 폭만 바뀝니다.


## 모바일

모바일 프레임은 좌우 마진 16px(`grid.margin.mobile`)을 씁니다. 피그마 모바일 프레임이 쓰는 변수 `Spacing/Semantic/Margin/Margin 16`을 참조합니다.

<Aside type="caution" title="아직 정하지 않은 것">
  브레이크포인트 경계값, 모바일 컬럼 수와 거터, 1440px을 넘을 때의 최대 폭은
  디자인 팀과 정한 뒤 토큰으로 추가합니다.
</Aside>
