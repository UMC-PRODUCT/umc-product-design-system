<Aside title="이름 읽는 법">
  `fill-primary-strong`은 피그마 `Semantic/Fill/Primary/Strong-200`을 옮긴
  이름입니다. 이름 끝의 단계 숫자는 지금 규칙에서 뺐고, 디자인 팀 확인을
  기다리고 있습니다. 전체 대응은 [피그마 정규화
  리포트](/contributing/figma-normalization/)에 있습니다.
</Aside>
