텍스트 스타일 하나는 서체, 크기, 굵기, 행간, 자간을 한 벌로 묶은 토큰입니다. 피그마 타이포그래피 문서 프레임과 컴포넌트가 쓰는 스타일을 모아 48개를 옮겼습니다. Tailwind에서는 `text-<스타일>` 유틸리티 하나로, vanilla-extract에서는 `typography.<스타일>` 객체 하나로 씁니다.

## 이름 읽는 법

Dev Mode에 보이는 텍스트 스타일 이름을 소문자 kebab-case로 바꾸면 됩니다. `SemiBold`와 `Semibold`처럼 대소문자만 다른 이름은 모두 `semibold`입니다.

| 피그마 스타일        | Tailwind                  | vanilla-extract               |
| -------------------- | ------------------------- | ----------------------------- |
| `Body/1-Regular`     | `text-body-1-regular`     | `typography.body1Regular`     |
| `Display/2-SemiBold` | `text-display-2-semibold` | `typography.display2Semibold` |

CSS 변수는 스타일마다 다섯 개입니다. `--umc-typography-body-1-regular-font-size`처럼 스타일 이름 뒤에 `-font-family`, `-font-size`, `-font-weight`, `-line-height`, `-letter-spacing`을 붙입니다. 글자색은 텍스트 스타일에 들어 있지 않으니 `text-neutral-default-900`처럼 [컬러](../color/) 클래스를 함께 씁니다.

## 피그마 값을 옮긴 규칙

| 피그마    | 코드            | 예            |
| --------- | --------------- | ------------- |
| 크기 px   | rem (기준 16px) | 48px → 3rem   |
| 행간 %    | 단위 없는 비율  | 120% → 1.2    |
| 자간 %    | em              | -3% → -0.03em |
| 굵기 이름 | 숫자            | Bold → 700    |
