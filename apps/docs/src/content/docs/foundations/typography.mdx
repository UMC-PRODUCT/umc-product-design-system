텍스트 스타일 하나는 서체, 크기, 굵기, 행간, 자간을 한 벌로 묶은 토큰입니다. Tailwind에서는 `text-<스타일>` 유틸리티 하나로, vanilla-extract에서는 `typography.<스타일>` 객체 하나로 씁니다.

## 피그마 값을 옮긴 규칙

| 피그마    | 코드            | 예            |
| --------- | --------------- | ------------- |
| 크기 px   | rem (기준 16px) | 48px → 3rem   |
| 행간 %    | 단위 없는 비율  | 120% → 1.2    |
| 자간 %    | em              | -3% → -0.03em |
| 굵기 이름 | 숫자            | Bold → 700    |

자간 단위가 퍼센트라는 것은 피그마의 코드 출력으로 확인했습니다. 36px에 -1.5%를 적용한 Display 3이 -0.54px로 나옵니다.
