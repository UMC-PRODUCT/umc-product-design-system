그림자는 피그마 effect 스타일 이름을 그대로 따릅니다. Drop은 요소를 띄워 보이게 하는 바깥 그림자이고, Inner는 눌린 느낌을 주는 안쪽 그림자입니다. 값은 피그마의 blur 반경을 CSS `box-shadow`의 blur로 옮겼고, 단위는 화면 배율과 상관없이 같은 두께가 나오도록 px로 두었습니다.

<DimensionTokens prefix="shadow." visual="shadow" />

## 쓰는 방법

| 도구            | 예                                             |
| --------------- | ---------------------------------------------- |
| CSS             | `box-shadow: var(--umc-shadow-drop-neutral-1)` |
| Tailwind        | `shadow-drop-neutral-1`                        |
| vanilla-extract | `vars.shadow.drop.neutral1`                    |

Tailwind 유틸리티는 기본 이름이 아니라서 `cn()`에 tailwind-merge를 쓰면 등록해야 합니다. `shadowUtilities`를 `shadow` 그룹에 넣으면 됩니다.

```ts
import { shadowUtilities, textStyleUtilities } from "@umc-product/design-tokens"
import { extendTailwindMerge } from "tailwind-merge"

export const twMerge = extendTailwindMerge({
  extend: {
    classGroups: {
      "font-size": [...textStyleUtilities],
      shadow: [...shadowUtilities],
    },
  },
})
```
