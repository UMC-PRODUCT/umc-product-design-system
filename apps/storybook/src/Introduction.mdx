# UMC Design System Storybook

`@umc-product/react` 컴포넌트를 직접 만져 보는 곳입니다. 컴포넌트마다 `Playground` 스토리가 하나씩 있습니다.

## 둘러보는 법

- **Controls**: 아래 패널에서 props를 바꾸면 화면이 바로 바뀝니다. 크기, 색, 비활성처럼 피그마 속성에 대응하는 값을 골라 보세요.
- **상태 강제**: 위 도구 막대의 상태 버튼으로 hover, focus, active를 켭니다. 마우스를 올리지 않아도 원하는 조합의 상태를 볼 수 있습니다.
- **화면 폭**: 도구 막대의 viewport에서 모바일 375, 태블릿 768, 데스크톱 1440을 고릅니다. 앱 컴포넌트는 모바일 375로 보세요.
- **배경**: 흰 컴포넌트는 도구 막대의 배경을 어두운 배경으로 바꿔 보세요.

## 모든 변형은 문서 사이트에서

피그마 변형을 한 화면에 모두 모은 그리드는 <a href={`${DOCS_SITE_URL}/`}>문서 사이트</a>에 있습니다. 각 컴포넌트의 문서 탭 맨 위 링크를 누르면 해당 페이지가 새 탭으로 열립니다.

목록이 열린 상태처럼 상태 강제로 켤 수 없는 모습은 `Opened` 스토리가 보여 줍니다.
